# 第二轮网页实现审查

日期：2026-10-29。范围：只读检查 `app/round2.js`、`app/round2.css`、`app/index.html`、`scripts/build-round2.py`、`scripts/check-round2.mjs`，并核对依赖的主页面显露时序。未改实现、未执行导出构建、未以静态审查代替浏览器验收。阅读任务B数据尚未齐时不运行构建。

## 需要修正的具体问题

### P2 · 首次证据深链存在隐藏容器加载竞态

位置：`round2.js` 的 `openHash` 及 `window.load` 监听（审查时第67–70行）；`index.html` 的 `#app-root[hidden]`。

初始页面主容器由 `main.js` 的异步 `fetch(research.json)` 完成后显露。`window.load` 不等待这个fetch。在研究JSON响应比页面资源慢时，初始 `#r2-T…` 深链会在隐藏祖先内执行 `scrollIntoView`，随后主容器显露但不重新定位。内部 `#round2-results`、结论和阅读区深链也需要在实际显露后恢复位置。

建议：主页面显露后发出ready事件，或只观察主容器hidden属性直到显露，再恢复本轮锚点位置；保留已经显露时立即定位的路径。不要依赖固定延时。浏览器验收覆盖一次带证据hash的冷打开即可，必要时对主JSON施加延迟。

### P2 · 重复点击相同证据链接不会重新展开已收起条目

位置：`round2.js` 结论证据链接与 `hashchange` 监听。

复现逻辑：点R14证据→条目展开、hash变为其ID→手动收起条目→回到结论再点同一R14。第二次hash值相同，不发生 `hashchange`；默认锚点只定位，条目仍收起。已有筛选将同一目标隐藏时也存在同样边界。

建议：给本轮证据链接的click添加显式“清除必要筛选、展开、定位”处理；hashchange继续支持外部深链和前进/后退。无需因此引入路由库。

### P2 · 实际来源清单未进入页面、报告和CSV

位置：`round2.js` 每篇正文构造；`build-round2.py` 逐篇MD与CSV字段。

输入的 `paper.sources` 包含来源类型及真实阅读范围，但页面只显示finding链接、DOI与readingLog，MD/CSV也没有导出sources。JSON保留此字段，因此没有丢失底层记录；不过关键证据的直接链接可能在用户实际阅读的界面中消失。例如P10第二条finding只链接Fig7，Fig6细胞过表达直接地址仅在sources；日志则从Fig1开始，不能直接到对应图。

建议：每篇添加“实际来源与阅读范围”列表，链接全部sources并显示type/readScope；MD和CSV同步保留此字段。这样模型归属结论能分别直达Fig6、Fig7，且用户看得到图注级和全文级的差别。

### P3 · 第二轮数据未加载时静默留白

位置：`round2.js` 第3–4行。

当 `round2-data.js` 请求失败或数据全局不存在，脚本直接返回；主程序仍可正常展示旧研究，而最新结果区仅剩标题，没有失败原因或替代读取入口。首页静态文字继续宣称17条复核，用户难以判断是空结果还是加载失败。

建议：本轮容器保留简短加载/错误状态；数据不存在时显示本轮JSON/MD的直接入口及重新载入操作。主页面通用错误只处理首轮research.json，不覆盖此分支。
