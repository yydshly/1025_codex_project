# 山竹红外影像 · 大范围版本

本版本仅扩大真实观测的空间取样范围，复用上级 `raw/` 中已经核验的 72 个 NOAA/JMA Himawari-8 B13 原始文件，没有新下载，没有覆盖旧版图片、清单或处理脚本。

范围为 **85°E—165°E、10°S—55°N**，EPSG:4326，2048×1664 像素；bbox 表示像素外边界，图像从北向南排列。经纬采样间隔为 0.0390625°，香港附近约 4.0 km 横向、4.35 km 纵向。它是输出取样间距，不代表仪器绝对定位精度。该范围全部位于本批观测的有效可见区域。

时间仍为 2018-09-16 00:00—12:00 UTC，共 72 帧；**02:40 UTC 原档缺失，不补帧**。名义时间、实际全盘扫描起止、原始文件 URL 和 SHA-256 均与原版一致。区域扫描时间估计随取样范围扩大而更新，不能当作精确逐像元时刻。

## 文件

- `himawari-b13-manifest.json`：本版本清单。`frames/` 相对路径指预处理目录；网页部署路径由应用数据包确定。
- `frames/*Z.png`：供显示的 RGBA 灰阶图；固定 180 K 白、310 K 黑，超出范围截断。原始有效像元 alpha=255，缺测为 0。
- `frames/*-bt-centikelvin.png`：16 位亮温数据，数值乘 0.01 为 K，0 为缺测。它保留超过灰阶显示范围的温度，不能当成普通显示图加载。
- `frames/*.json`：逐帧原生投影、标定系数、扫描行时间和处理元数据。建议随研究资料保留，网页运行无需加载。
- `processing-config.json`、`validation-report.json`：版本参数、脚本哈希及全量校验记录。

精简交付项目中，RGBA显示图统一放在 `../../../app/assets/events/himawari8-b13-wide/`，避免与预处理目录重复复制；`frames/` 保留数值PNG和逐帧JSON。清单中的显示图相对路径描述重处理布局，应用清单使用实际网页路径。

原始 HSD 仅保留在现有 D staging 的上级 `raw/`，不重复复制到交付项目或网页。复制本版本时应保留清单、逐帧 JSON、数值资料、脚本和报告；应用只需显示图及运行用清单。

## 科学含义与显示边界

标定、导航与空间最近邻方法沿用原版，并且没有时间插值。云视差仍未校正。第 13 波段亮温包含云和无云地表的信息，既不是自然色，也不是云量、降雨或风速。

本目录图片**没有烘焙边缘淡化或温度到透明度的映射**。应用中的暖区淡出和边缘融合只是一种显示映射，不是云掩膜：透明不代表无云，边缘淡化不代表缺测。原始灰阶可用于对照；8 位灰阶反推温度仅为量化、截断后的近似值，精确数值检查使用 16 位资料。

来源、署名要求和 HSD 格式依据见 [上级说明](../README.md) 与 [NOAA/JMA 数据登记](https://registry.opendata.aws/noaa-himawari/)。处理后的图像应标明本项目完成标定、重投影和呈现，不称为未经修改的原图。

## 复现与验证

需要 Python 3.10 或更新版本、`numpy`、`Pillow`。在本目录运行：

```powershell
python ./process_himawari.py
python ./verify_wide.py
```

这两个命令需要上级原始 `raw/`，验证还需要上级原版清单与处理脚本。如果仅有精简交付包，先在工作副本中按上级说明重新获取限定半日的 72 个原始文件；不能把留存的验证报告当作本次重新执行的结果。处理默认逐帧运行，输出到本目录，不修改上级数据。
