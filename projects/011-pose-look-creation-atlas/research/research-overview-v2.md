合成采用内置 ImageGen，图中照片和素材来自已有文件，不下载新图库。首次完成记忆版排版；第二次尝试补充坐姿对照因网络错误没有返回图片，未把坐姿写成交付。一次初始七参考请求被工具在生成前拒绝，原因是最多五个参考；记录保留该限制。最终交付一个 1448×1086 PNG。

信息图的缩略图经过 AI 排版，局部可能重绘。网页因此提供“总览图 / 原库 P015 / 完整衣装预告 / 庭院结果 / 婚纱结果 / 初版文字图”的当前窗口切换、缩放及当前文件下载，以原始文件作为精确回看依据。[完整记录](../app/media/research-overview-v2/manifest.json)保存输入顺序、各文件哈希、两阶段指令、成功和失败状态。

含源素材缩略内容的成图放在 `.local/research-overview-v2/overview.png`，受现有 Git 忽略规则覆盖。公开 app 只保存不含原图的元数据及接入逻辑。专用本地路由验证 PNG 签名、字节、尺寸和记录哈希后才返回文件；Host、跨站和方法限制继续适用。公开静态版自动使用 v1，不包含记忆版图片。含原素材的网页核验截图也只保存在 Git 忽略目录。

原图限制依据既有归档研究；本轮未扩大原图使用范围，没有生成新写真、视频或 3D，也不把衣装预告或婚纱分支当作已经验证的产品能力。
