# 本子项目协作约定

- 这里保存内容与交互统一设计方法及其应用方案。处理新的主题时，先读 `README.md`、`method.md`，再用 `templates/topic-brief.md` 整理方案。
- 先建立主题、载体、贯穿对象、章节接续和持续风格，参考 `experience-map.md`；每章写清承接什么、增加什么发现、带到下一章什么。
- 写清内容、视觉、讲解、操作和反馈的对应关系，让每章推进整段主题体验。
- 新主题方案放在独立目录中，保留通用模板和既有示例；用户要求另建子项目时，遵循总库的编号创建流程。
- 依据主题选择表现形式。需要空间关系时再引入 3D，保持对象身份、颜色含义、交互动作与讲解状态一致。
- 涉及事实、模型或来源材料时，标出依据、假设和适用范围。设计示例、预期效果和实际试用结果分别记录。
- 实现原型后按 `review-checklist.md` 检查主要流程；只请求方法或方案时，交付相应文档。
- 索引中的源仓库是本研究总库；Every Joule 是灵感来源，不能称作其源码仓库或复制其未获授权素材。
