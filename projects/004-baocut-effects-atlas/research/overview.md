# BaoCut 能力与价值总览

> 本研究根据讨论与固定版本资料整理。能力说明与实测结果分开；尚未运行 BaoCut。

固定提交：`228c6aecf91ee2e3235b72a93223b0dd7cbb92fa`。

## AI 可操作的视频编辑器与制作工作流

按用途定内容，按材料选做法，把画面、声音与文稿组织成可继续修改的视频工程。

Skill 提供方法：简报 → 分镜 → 风格与样段 → 制作 → 验收

BaoCut 提供执行环境：素材库、时间线、编辑器、任务与导出

## 五类用途

- **图形与动效**：排版 / 形变 / 物理 / 程序化 3D；5 个方向 / 5 段预览。
- **讲解与教学**：机制图解 / 数据故事 / 操作教程；6 个方向 / 3 段预览。
- **产品与推广**：发布片 / 产品展示 / 界面演示；5 个方向 / 5 段预览。
- **素材与剪辑**：混剪 / 活动回顾 / Vlog / 口播；4 个方向 / 3 段预览。
- **故事与氛围**：电影感 / 预告 / 绘本故事；4 个方向 / 4 段预览。

五类是用途，三条是画面制作路径；同一用途可以混用多条路径。数量按 24 份制作记录的主要画面来源统计。

## 三条画面制作路径

### 代码绘图与动画

AI 写程序，程序计算每一帧。

文字、图形、数据与规则 → 按时间绘制或模拟 → 渲染成镜头 / 导入代码包

- 排版、遮罩、形变、缓动
- 图表与机制图解、界面示意
- 碰撞事件、节拍同步、程序化 3D

效果取决于动画设计与代码；具体绘图库以记录为准。

代表样片：解压物理动画、排版动效短片。

### AI 静图与代码运镜

AI 生成外观，程序移动取景框。

生成关键静图 / 多格分镜 → 裁图、平移、缩放与叠字 → 把静图组织成连续镜头

- 风格与角色参考、分镜拆图
- 推近、拉远、平移、裁切
- 标题包装、镜头节奏与衔接

静图运镜没有新增角色表演或真实物体转动。

代表样片：电影感场景、故事短片。

### 已有素材与剪辑包装

动作来自原视频，AI 选段和编排。

拍摄视频、录屏、照片与声音 → 选段、裁切、重排与变速 → 转场、字幕、包装与混音

- 按内容选段、剪口与去长停顿
- 画幅重构、照片运镜、图文叠层
- 音乐剪点、原声桥接、淡入淡出

内容与动作受原素材限制；部分包装需要先渲染。

代表样片：创意混剪、Vlog 剪辑。

## 配套与工程能力

以下为固定版本文档说明的能力；模型、索引或服务需要相应配置。本研究尚未安装并逐项运行验证。

### 文稿与字幕

- 语音转写、逐词时间与说话人
- 翻译、原文 / 译文 / 双语字幕

精度依赖转写、翻译与对齐能力。

### 素材查找与选段

- 按语义或画面描述找候选片段
- 口播剪辑提案、章节与高光选段

语义 / 画面检索需要模型与索引，候选需核对。

### 配音与声音

- TTS、跨语言配音、人声分离
- 配乐 / 音效、混音与人声闪避

配音与配乐依赖可用模型；音效可由内置配方合成。

### 合成与输出

- 时间线剪辑、转场、文字与内置声波
- 视频、字幕、音频、便携工程导出

媒体准备与视频导出仍需 FFmpeg / FFprobe。

### 汇入同一个可编辑视频工程

素材 ＋ 镜头 ＋ 时间线 ＋ 文稿 ＋ 字幕 ＋ 配音

- 图形界面 / CLI / MCP 共用运行时
- 事务、版本检查、回执与撤销
- 按对象修改、人工接手、制作计划增量更新

依赖关系有明确适用范围；已经烧进画面的文字和效果，修改仍需重新渲染。

需求与材料 → 分镜与样段 → 按需组合制作 → 预览与修改 → 导出与交付

## 对我们的价值判断

### 已有技术能完成什么

代码动画＋FFmpeg 可完成同类画面与合成。
生图、转写、配音和剪辑也可自行集成。

### BaoCut 主要额外解决什么

把多种工具、项目状态和编辑入口接在一起。
减少反复修改、素材管理和人工接手的配套工作。

### 对我们什么时候更有用

一次性代码效果：新增收益可能有限。
多素材、多轮修改、多人接手：更值得实测。

## 边界

- 固定版本明确没有 AI 视频生成；本批制作记录没有成功的视频模型生成路径。
- 24 个方向和 20 段预览展示特定结果；不等于 24 种技术，也不等于稳定复现。
- 本研究未运行 BaoCut；质量提升、速度、成本与修改效率均未作对照实测。
