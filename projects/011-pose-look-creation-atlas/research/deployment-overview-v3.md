日期：2026-10-29。公开地址：[研究网页](https://yydshly.github.io/1025_codex_project/011-pose-look-creation-atlas/)。

本次将此前本地整理的原库盘点、姿势生成小样、六张写真候选、选片方案和产品目标汇总到公开研究页。首页及总库摘要分别交代两个来源：

- **衣装参考分享**：约 1,000 套的制作预告与人物、衣装、姿势多参考生图演示。目前只取得一张预告拼图，完整库、开放下载和商用条款尚未确认。

两者是素材条件；图片生成、身份保持、衣装细节与姿势跟随由外部模型及流程实现。当前只以虚构成年人物做小样，写真、穿搭、婚纱、图文故事及个人品牌方向分别标注已完成候选、独立分支和待验证任务。未把图库说成已实现换装、视频或可编辑 3D 的软件。

## 发布范围与使用

- GitHub Pages 公开 `app/` 与逐项声明的引导封面，展示总览、两来源说明、已有结果、选片备注、导入导出、工具能力及来源快照。
- 公开版不请求本地 API，也不请求私有姿势图片。原图入口指向原站；原图浏览、五视角、收藏和参考编排在本人本地服务中继续使用。
- 本地 Node 服务根据文件签名、尺寸、字节及 SHA-256，读取私人合成图；公开静态站使用 v3 引导图。浏览器草稿按来源分别保存在本机，不上传。
- 部署在从远端 main 建立的独立工作树完成，仅提交项目 011、对应登记和封面配置、生成索引，以及登记变化所需的 010 回查快照。
- 私有备份只同步研究项目和指定的私人记忆图；不备份运行日志、PID 或测试临时文件，不变更原图。
