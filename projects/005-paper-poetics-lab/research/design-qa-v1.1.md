## 视觉问题与修正

| 原问题 | 本轮实际改动与复查 |
| --- | --- |
| 茶器是扁平展台上的简化模型 | 重建透视窗景、木台、浅石茶席、壶足与薄杯沿、壶嘴开口；青灰釉面、PCF落影和小范围接触影共同建立体积。三幕实际截图已检查。 |
| 茶席首版影子过硬、瓷面像白塑料、山峰过近 | 缩短并降低主影强度，扩大过滤半径；调低环境反射与clearcoat，增加粗糙度；山脊降低、后退并减淡。保留初次重做的 `tea-redesign-pass1.png` 供对照。 |
| 花庭为巨大白盘、图标花和椭圆池 | 重建有厚度月洞门、石阶、近处曲面花冠、中景水平反射池与远庭树。缩小并纹理化月亮，用几何倒影建立水面关系。 |
| 首版墙体过大、主体太暗，第二轮又过亮 | 前移镜头、扩大门洞在画幅中的占比，保留银色补光，同时降低外墙材质亮度；花冠改斜向展开。过程截图为 `moon-redesign-pass1.png`、`moon-redesign-pass2.png`。 |
| 月亮和花重叠，手机被墙沿或门洞挡住 | 分别调整桌面、偏方、手机的月位置；手机降低远墙顶沿。最终手机两幕和942窗口截图已重新检查。1280前两幕保留少量自然树叶剪影，末幕月与主花分离。 |
| 三幕近似同一张图 | 茶息由窗前宽景进入注水，再靠近杯汤与余热；花庭由闭合花苞进入绽放，最后靠近主花与水影。变化由progress直接计算，暂停后定位也能到位。 |
| 文字和操作占据画面 | 短题与两行诗句取代常驻解释，隐藏重复上下幕按钮；手机抬高文字避开墙顶线。默认自动看三幕，手动定位接管；减少动态偏好下不自动推进。 |
| 画面过于清晰规整，纸本气质薄弱 | 改为线性HDR、ACES映射、环境反射；保留少量静态纸粒，补入轻微远景深度虚化与不规则纸边。虚化是艺术处理，不是完整光学景深模型。 |

## 结论与边界

旧版 [v1.0记录](research/design-qa-v1.0.md) 的 passed 只说明当时交互走通，不能作为视觉质量结论。本轮完成了空间和构图重做，实际截图显示三幕差异以及更明确的接触、遮挡与水面关系。它仍是程序生成的原创场景原型，不能将这些检查等同于最终美术质量保证。

仍保留的限制：花瓣和器型有程序生成特征；石墙、木纹和茶汤细节偏简化；纸边和景深属于风格处理；水线、反射和环境声不是完整物理模拟。未做实体手机、多GPU或长时间发热/显存测试。首次着色器编译有等待提示，没有宣称稳定60FPS。音乐继续复用002《纸上归途》，没有新增两首独立配乐。
