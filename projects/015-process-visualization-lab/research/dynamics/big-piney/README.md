# Big Piney 实地示踪数据

USGS 于 2021 年 8 月 25 日在美国密苏里州圣罗伯特附近的 Big Piney 河开展罗丹明 WT（RWT）控制示踪实验。三个监测断面距离投放处约 1,485、2,650 和 3,670 米，各有一支靠近左岸和一支靠近右岸的荧光计。左右岸以面向下游为准。投放断面的经纬度未见于本数据发布，场景采用断面实测位置与沿河距离。[USGS 发布与引用](https://doi.org/10.5066/P14DAOJF)

## 时间与读数

CSV 有 21,575 条荧光计记录。数据包保留源表行号、当地时钟字符串、源表的投放后小时数、RWT 浓度和浊度。RWT 是 USGS 已做背景荧光校正与去尖峰的发布值。浊度作为对应源记录保留，浓度回放使用 RWT 的 ppb 值。

统一时间轴以文献所述当地约 15:07 为零点，减去起点后的时间每 30 秒一个刻度。全部 CSV 记录的 `hrs_pst_rel` 在两位小数允许的舍入范围内匹配该起点。CSV 未标时区，来源摘要和处理步骤的时区用词不一致，所以保留当地原记录与相对时钟。3,670 个刻度覆盖投放前 4 小时 7 分至投放后 26 小时 27 分 30 秒。六个序列开始时间相同，结束时间各异。某岸停止记录后，该岸对应刻度缺测。发布值为零的刻度保留零。

章节中的持续信号标记采用回看规则。投放后，找到连续三条至少 3 ppb 的记录，把标记放在这组记录的第一条。3 ppb 高于六支仪器投放前的最高发布值 2.98 ppb。这一规则用于统一回放中的比较口径。仪器检出限与染料首次抵达时刻未作判定。峰值时刻取各仪器完整记录的最高值。

## 坐标与复核

保留原始 NAD83 / UTM 15N 的东、北向坐标。地球经纬度用 GRS80 椭球的逆横轴墨卡托投影和 EPSG:1188（NAD83 到 WGS84）生成。六点与 PROJ 独立计算的最大角度偏差小于 0.000000002°。EPSG:1188 的标称精度为 4 米，显示小数位数只用于保存转换结果。场景中心为六个测点的经纬范围中点。[USGS 投影公式](https://pubs.usgs.gov/pp/1395/report.pdf) · [EPSG 坐标操作](https://epsg.io/1188)

原始文件与 SHA-256 记录见 [下载凭据](source-receipt.json)。CSV 与 FGDC 元数据按原文件归档，数据发布使用 CC0。生成脚本只用 Python 标准库。从子项目根目录执行下列命令即可生成和逐行复核，`--check` 检查发布 JSON 的完整字节内容。

```powershell
python research/dynamics/big-piney/process_tracer.py
python research/dynamics/big-piney/process_tracer.py --check
```
