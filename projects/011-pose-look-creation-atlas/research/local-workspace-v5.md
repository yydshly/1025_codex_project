# 本地原图工作台与向上产品探索

日期：2026-10-29。按用户要求先完成本地接入，暂不提交、推送或部署远端。

## 从资源到交付

用户所说的扩展是“基于姿势素材向上做什么产品”，不是增加图片数量。原图库继续作为主体，既有婚纱/换装实验保留在分支。当前实现的是能操作的原图工作台和创作计划原型，后续制作与生成效果尚未验证。

| 产品方向 | 用户与问题 | 当前能交付 | 后续价值验证 |
| --- | --- | --- | --- |
| 创作参考方案包 | 画师、角色设计师、委托合作需要解释选图、机位和意图 | 原图引用、视角、选择理由、顺序、备注、可恢复 JSON 与创作说明 | 比较找图耗时、沟通轮次、误解及修改次数 |
| 角色系列图制作计划 | 插画/IP 创作者需要规划同一角色的多张画面 | 角色与风格约束、动作清单、逐图任务、修改记录 | 真实制作中是否减少动作重复与遗漏；外部模型的身份、服装与画风仍需独立验证 |
| 分镜与机位方案板 | 漫画/短片前期需要讨论几个关键画面 | 静态姿势顺序、视角、景别和叙事意图备注 | 是否降低分镜沟通与返工；没有动作过渡、时间数据或自动视频 |

这些方向可使用同一套方案板原型，但服务的任务与交付不同。不能把三个模板说成三个已成熟产品，也不据此认定存在付费需求。

3D 摆姿/镜头预演需要可编辑人物、骨架、相机与实际接收软件验收；姿势控制/生成评测需要检测和生成模型以及独立效果记录；真人摄影、换装、婚纱则需要适当授权的其他姿势、人物与商品素材。这些仍是后续方向。

## 本次实现

- Node 本机服务读取外部原图目录。通过清单白名单提供图片，不复制或改写原图。
- 原始索引按姿势分组，全部 1,439 张可通过 288 组访问；已知四视角组明确显示缺项。
- 分区、动作分类、中文译名/日文原名/编号搜索、视角预览、收藏和分页。
- 98 个人工中文译名（73 标准单人 + 25 上半身手势）；六类名称规则标签，五个自编专题。原名保留，不把规则标签称作视觉识别。
- 原图详情显示多视角、尺寸、来源、SHA-256，支持按需另存当前图。
- 方案按图片视角选取，最多 12 张；支持排序、移除、逐项备注和统一目标。
- 草稿与收藏存在浏览器 localStorage；导出 JSON 可恢复引用，导入会合并去重并保留已有草稿；制作说明可导出或复制。
- 原作者服装预告拼图可在本地展开查看，仍未取得完整服装图库。

## 本地与远端边界

本地服务仅监听 127.0.0.1，白名单读取图像，拒绝跨来源请求与任意文件路径。无上传接口，不调用模型、不安装依赖。默认原图目录由环境变量 POSE_LOOK_LIBRARY 可替换，端口由 POSE_LOOK_PORT 可替换。

`.local/` 保存启动日志、进程记录及核验示例；`assets/images/local-v5/` 保存本地截图。两处均被本子项目忽略，包含原图的截图不进入公开仓库。现有原图私有备份不变。本轮没有把新增工作台快照推送私有仓库，也没有修改线上页面。

后续统一处理远端时：工具源码与研究说明可提交总库；原图及含原图的截图与完整原索引应维持有权限的私人关联，不能凭代码开源扩张素材用途。方案元数据不内嵌原图；使用者仍需相应素材权限与本地原图库。

## 启动

在子项目运行 `npm.cmd run start:local`，访问 http://127.0.0.1:8011/app/#gallery 。运行 `npm.cmd run stop:local` 可停止本工作台隐藏服务；没有系统自启动任务。

本机服务应保持运行供用户验看。原图目录只读，未清理、移动或新增下载任何原图库文件。
