# 008 · 星光卡片基地

一个面向亲子探索的人物图鉴、随机卡片展示与网页演出实践。[返回总索引](../../README.md#项目索引) · [研究总览网页](app/guide.html) · [抽卡体验](app/index.html) · [实现笔记](research/notes.md)

## 研究与效果总览

![星光卡片基地：从人物图鉴到孩子的随机探索剧场](assets/images/project-overview-v1.png)

项目的目标是把已收集的人物形象、简介与来源变成可随机演示的亲子素材，让孩子看形象、听介绍、继续探索。整体分为人物素材库、人物演出配置、卡片展示舞台和随机演示体验；家长无需先逐张录入才能使用人物图鉴。

当前已有 874 条人物与形态资料、4 位精选角色的代表招式配置、2 位角色的透明前景，以及搜索、随机抽取、大图、页面光效和设备语音讲解。后续可在这套基础上增加标志姿态、互动动作和招式短动画，并丰富分层、光线粒子、镜头与音画节奏，再接入同一随机展示流程。动作素材、播放控制和具体渲染仍需逐项制作与接入，图中的后续扩展尚未实现。

图中人物和卡片是基于现有页面与风格化人物素材生成的效果示意；资料条目包含不同形态，不代表完整卡游实体卡目录。图片使用内置 imagegen 工具制作，人物权利归相应权利人；[生成提示词](research/overview-image-prompt-2026-10-27.txt)与[制作记录](research/overview-image-2026-10-27.md)随项目保存。

## 使用方法

直接在浏览器中打开 [app/index.html](app/index.html)，无需安装依赖。人物数据随项目保存，部分人物图片和资料链接需联网。也可以从项目目录启动本地静态服务器：`python -m http.server 8000 --directory app`，然后访问 `http://localhost:8000/`。

首页点击“抽一张卡”可随机展示人物图鉴中的角色及其介绍；也可切换抽取范围为“我的收藏”或两者合并。人物图鉴现有 874 条人物和形态，可按名称和类别筛选，点击卡片查看介绍及资料来源。已收录人物可直接使用，无需录入；这个目录是人物主题卡，并非完整的卡游实体卡编号或卡面图鉴。

抽中人物后，可以点击卡片上的按钮触发星光或招式光效，并点击“听人物讲解”由设备朗读介绍；再次点击可停止。朗读使用设备的合成语音，是原创讲解，并非角色原声或原作台词；设备不支持时仍可阅读文字。初代、迪迦、赛罗和泽塔配有已核对的代表性招式，初代和迪迦还使用原创风格化人物前景；其他人物与自己的收藏使用通用舞台效果。动作光效是页面演绎，不是角色实际视频。系统开启减少动态效果时动画会减弱。

人物卡上可直接“再抽一张”或“查看大图”。连续抽取在候选人物超过一位时避开上一条；从图鉴选择人物会直接定位到卡片。大图支持关闭按钮和 Escape 键，切卡、打开大图或离开页面时会停止语音。

下方“我的卡片收藏”仍可按名字、卡号、版本或类别筛选。点“添加卡片”填写角色名称、类别、卡号、版本和人物介绍，也可上传照片。录入名称与图鉴人物完全一致时，空白介绍会预填该角色的简介，可自行修改。重复角色、不同版本和重复收藏可分别录入。点击收藏卡片可查看，卡片下方可编辑或删除。

个人收藏中的初始卡片为**角色示例**，不代表家里已经拥有这些实体卡片，也不包含虚构的卡号和版本。人物图鉴与个人收藏分开保存，升级时不会覆盖已有收藏。人物资料来源见每张主题卡的“资料来源”；人物形象包含圆谷图鉴或国际对战卡牌图片、万代手办图片与第三方图鉴图片。在线图片需联网加载，版权属于相应权利人；未加载成功时显示提示，其中八位角色可以回退到本地 AI 风格化插画。

## 保存与备份

收藏及图片只保存在当前浏览器的本地存储，不会自动同步到其他浏览器或设备。清除浏览器数据、换设备或使用不同的本地地址可能造成数据不可见或丢失。建议在录入后定期点击“导出备份”，妥善保存 JSON 文件。导入先校验格式并要求确认；确认后会**替换**当前全部收藏，不会合并，建议先导出当前数据。

浏览器存储空间有限，上传图片会先压缩。空间不足或保存失败时页面会提示，原有收藏不应被更改。私密照片和备份文件请自行妥善保管。

## 实现和来源

使用原生 HTML、CSS 与 JavaScript；人物数据随项目保存，部分外部图片和资料链接需要联网。`app/profiles.js` 按人物 ID 存放精选角色的舞台颜色、招式、讲解和可选前景；没有配置的角色自动使用通用舞台，人物数据和个人收藏仍分别保存。人物介绍为简短概述，不是完整百科，也没有声称为真实收藏或全量卡游实体卡。项目为本库原创实践，非官方产品；奥特曼及相关角色属于其权利人。尚未部署在线演示。
