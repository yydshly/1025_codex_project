# 七个景观动态方向：基础设计稿

这些方案把已经形成的创作准则扩展成七个可测试方向：美景是主舞台，人物提供路线与尺度，摄影带观众进入空间，动作带来新的观看收获。《悬崖长卷》已完成5秒模型对照和11.041667秒双片拼接实测，其他六项未生成视频。此次拼接验证不等于原10秒分镜全部要求已通过，概念图本身也不能证明动作可执行。网页数据见 [concepts.js](../app/data/concepts.js)，其中包含每条可复制的首图提示词、视频提示词、分段时间与验收条件。

《悬崖长卷》的概念图已用于运动短样，后续续段则以A片真实末帧起步；其余配图仍为视频待验证的概念视觉。概念图可以展示机制或高潮，不等同于已验收的视频起始帧；`firstFrame` 与 `imagePrompt` 描述的是制作起始图的要求，执行时需核对或另做符合初始状态的图片。本轮交付仅在本地，不部署、不提交。

每条以 **16:9、10秒** 为设计长度，探索阶段优先用适合运动的较好视频模型与 **720p**。时间段、人物比例、运镜路径都是创作目标，不是模型承诺。根据测试结果可以使用明确换机位的剪辑，但应单独记录源片、剪点和变速，不能把编辑后的连续感写成原始生成的单镜头能力。

## 设计从哪些经验出发

已完成的试验说明：锁定机位、让小人物缓慢移动，可以生成有动态的风景，却无法替代参考片里的空间推进、近身追随和近远视差；提高分辨率也没有解决这个偏差。历史跃岭试验A展示了有效的越岭揭湾，却提前起跳、跳得偏高，并在末帧之前落地，未实现原计划的腾空终态。该次B的下降与落地反馈更清楚。8.375秒短片采用两机位与A空中部分2倍速，并保留可辨的空间、色调差异。

后续《悬崖长卷》将问题推进到真实多片连接：两条Kling 4.0原片用A真实末帧建立B起点，再按实际帧区间硬切成为11.041667秒。人物与主要地理基本接上，但B首帧仍有重绘，摄影速度也不是由同一首图自动继承；B后段的明显拉远需要作为实际结果记录，而不能写成严格执行了“轻微升高”。

因此，新设计不把“写了秒数”“提供首尾图”“衣服颜色一样”当成可靠控制。每条先识别一个真正决定作品是否成立的问题，最小测试围绕这个问题展开。首图负责建立物体、路线、遮挡和待发生状态；视频负责改变观众的观看位置与事件状态；剪辑负责组织实际得到的素材。

## 全系列固定规则

- **景观占主要观看面积。** 骑手可暂时变大以看清动作，但不机械追求人物近景。首图要留下尚未展开的空间、状态或尺度。
- **人物身份作为独立检查项。** 默认单一红衣骑手、黑短裤、黑头盔、深色背包及同一双轮自行车。背侧机位降低面部一致性的依赖，但不能因此免检身体、车架、车轮、手脚与接地。
- **路线先于动作。** 首图需看见人物所在位置、前进方向及可通行下一段道路。没有跳跃价值的方向保持普通骑行，不重复把跃岭当作通用高潮。
- **荒诞只引入一个机制。** 巨门内有海、门影领先、花种载岛、踏板唤灯、隐藏的微缩尺度、门洞分隔季节，各自保持可描述的世界规则；周围运动和摄影承担理解依据。
- **世界稳定不等于画面冻结。** 建筑和地形在世界坐标中一致，相机移动时允许它们在画面中移位、被遮挡或显露。
- **素材角色必须真实。** 每条为新机位设计首图，继承海湾、巨崖、草坡、拱门与花草的世界语言。未实际输入完整参考视频时，不能写成“已给模型动作参考”。
- **声音是待执行设计。** 数据中的风声、轮胎、石门、叶声等属于声音意图；未听验的生成结果不能声称实现。概念图资源路径也不代表图片已经生成。

## 01 · 悬崖长卷 / coastal-scroll

**命题：旅行的满足来自不断多看见一点。** 这是系列的基准方向，主要用正常物理、侧向摄影和遮挡变化建立风景价值。它适合检验“画面在动”是否真正转化为“观众在进入空间”。

首图采用侧面广景，骑手位于左下三分之一，人车约画高20%，前进方向留出空间。画面分为近花草、连续土路、部分被坡肩遮挡的水面、远处拱廊巨崖。不要把整个海湾和每座瀑布都在首帧铺开，否则后续横移只有重复。

10秒结构：0–2秒平行跟骑建立方向；2–5秒经过坡肩缺口，水面与瀑布依次露出；5–8秒小路轻弯，相机渐成后侧并略升高；8–10秒放慢摄影节奏，人物继续前进，风景得到停留。主情绪是轻快到舒展，暖日光和海蓝、草绿服务于清楚的层次。

首轮先测试5秒横移，观察近处花草是否明显快于远崖、坡肩是否真实解除遮挡、小路是否继续连通。最大风险是整张图平移、数字放大或远景建筑反复增生。没有明确空间揭示时，先调整机位与遮挡，而不是添加水花、光晕或更多粒子。

**当前实测：已完成11.041667秒双片拼接。** [本地观看](http://127.0.0.1:4333/?film=coastal-scroll-splice-v1#screening)。先前Seedance 2.0五秒样片有横移与视差，也有首秒短暂浮起和持续靠近；Kling 4.0 A任务1044781的人物尺度相对更稳定，但仍略微靠近，前段花草遮挡下的全程接地难以确认。这是具体样本比较，不是模型普遍排名。

此次B任务1044794使用A第120帧作为实际首图，原片145帧、6.041667秒；两原片均为1284×724、24fps。编辑保留A第0–119帧的5秒，再接B第0–144帧，共265帧、1280×720、24fps，在5.000秒硬切。A末帧从A中剪除，避免相似边界姿态重复；没有循环、定格、变速或溶解。[剪辑记录](coastal-scroll-splice-v1-edit.json)与[实际接点图](../assets/images/coastal-scroll-splice-v1/actual-seam.jpg)保存这个连接方式。

接点人物、脚踏相位和主要地理基本承接，未见明显动作倒回；人物与花草有轻微重绘、柔化。B前段延续跟骑，后段明显拉远，景观的观看面积增加，不能称严格无缝或全程匀距。当前B确认实际180积分，当前A最终费用未知，合计不补推；音频未听验。此状态与历史跃岭片“已知A75、B未知”分别记录。下一轮先检查接点正常速度感受、脚轮接触与声音，再决定是否修正单个变量；其余六个方向继续保持视频未生成。

## 02 · 门中海 / inner-sea

**命题：先相信门的重量，再发现门后容纳不了的辽阔。** 唯一异常是悬崖内部存在另一片海；门扇、骑行与摄影都提供熟悉的物理关系。

首图从门外左侧斜看。关闭的双扇石门及厚拱框占右半画面，外海仍在左侧，骑手沿门前连续道路驶过。门扇向内开启，路线避开扫过范围。第一张图不展示打开后的完整内海，门缝细光只提供将发生变化的线索。

0–2秒建立门框、门槛和外海参照；2–5秒石门绕各自铰链向内开启，骑手略看后继续前行；5–8秒相机侧移越过近门柱，内海岸线和远山显露；8–10秒人物离开主视区，让门后景观停留。通过厚度、柱体遮挡、门槛和纵深来证明门后是空间，而非门面上一张海景。

首轮只测试5秒开门与纵深，骑手可延后加入。重点检查刚性、铰链和内外关系。若门框融化、整个场景直接换成海景，机制便没有成立；不能只凭最后一帧漂亮判为成功。

## 03 · 倒影先行 / reflection-first

**命题：世界的影子知道下一刻会发生什么。** 实体门与倒影必须同时进入观众视线，才能让时间差成为可亲自发现的事件。

首图将实体门放在右上、完整门影放在右下平静水域，两者均关闭。二者各约画高20%，确保在720p小样中也有机会分辨状态。骑手在左侧岸路，只提供经过和轻微侧看的回应，不遮住比较区域。其他倒影保持正常，风与细波不能吞没门影。

0–2秒建立正确映射；2–5秒只有门影开启，实体保持关闭；5–8秒实体以同样方向开启，门影在打开状态等待；8–10秒两者恢复对应，人物继续沿岸前进。中段相机轻移后稳定，不用切镜或全画面波动掩盖难点。

这是高风险时序设计。首轮只做5秒“实体关闭、倒影开启”，暂不要求完整时间追上。若模型自动使两者同步，或把倒影生成为水中另一个实体门，需如实判为未通过，而不是把普通镜像效果解释成时间异常。

## 04 · 花种载岛 / seed-islands

**命题：花草不只是装饰，也是世界生长的方式。** 一颗蒲公英种子托着草岛与小拱门，从花头脱离后向海湾远去；不扩展成满屏浮岛或粒子风暴。

首图从地面骑手后侧偏低处观看。左上是巨型蒲公英，目标种子的冠毛、种柄、草岛与小拱门连接清楚，仍连着花头；右侧海湾留出漂移路线。骑手在下方连续土路，始终在地面。首先建立“花种天然载岛”的世界规则，后续只改变连接状态和位置。

0–2秒骑手经过花茎，冠毛轻摆；2–4秒单颗种子脱离；4–7秒种子整体顺风漂移，相机小幅仰起并保持地平线；7–10秒种子远去变小，海湾成为旅程的去处。晨光透过冠毛、柔和风声与稳定漂移服务轻盈感。

首轮验证单颗脱离与刚性载物。检查是否凭空复制种子、种柄断续、草岛改变形状，以及骑手是否被错误带离地面。种子变小应来自远去透视，而不是各部件分别缩放。保持地面和海湾锚点，比增加空中装饰更有价值。

## 05 · 踏板唤醒城市 / pedal-city

**命题：普通人的小动作得到巨大世界的回应。** 机制是踏行让窗灯逐段点亮，暂停踩踏使新灯暂停，重新踏行才继续。暂停是观众理解因果的关键，而非单纯节奏装饰。

首图处于蓝调清晨，窗带尚暗但建筑细节可见。骑手在左下，人车约画高30%，脚踏与腿部能辨认；远崖分成三组固定拱窗。不要把地面做成发光线路，也不要同时开启门、瀑布和飞行物，以免因果失去焦点。

0–2秒踏行唤亮第一组；2–4秒继续踏行唤亮第二组；4–6秒双脚停止踩踏而车仍滑行，新灯暂停、已有灯常亮；6–8秒恢复踏行才亮第三组；8–10秒稍放宽景别，让城市成为观看回报。相机需兼顾踏板与远景，不能太早拉到看不清腿部的全景。

首轮5秒仅测试两组窗与一次暂停。跨尺度时序不应被说成可可靠编程控制。如果灯光独立闪烁，或人物停踩时车也骤停，就没有建立预期因果。先简化动作和窗组，再考虑完整10秒；这是设计假设，不是已测能力。

## 06 · 微缩海湾 / miniature-bay

**命题：辽阔与微小取决于观看位置。** 整片海湾从始至终就是湿润石洼中的微缩世界，相机后退才揭示它；不存在人物、建筑或海洋在镜头中各自缩小的第二种机制。

首图从石洼内部低位观看，让海湾、巨崖和骑手按宏大风景构图。右下只露无法判断尺度的一段弧形湿石边，完整容器尚未入画。固定一座拱门、三处岛礁与一条弯路作识别锚点，外部野花暂处画外或仅为模糊边缘。

0–2秒内部跟骑；2–5秒相机后退升高，近侧石边逐步进入；5–8秒跨过边缘，外部花叶提供真实尺度；8–10秒保留俯斜全景，内部骑手仍沿路前进。情绪由进入辽阔转向发现小世界的珍贵，声音设计也可随距离让轮胎声变弱、草叶风声增强。

首轮验证5秒拉远中的锚点、遮挡与视差。石边突然出现、穿过建筑或内部地理被重绘，都是空间揭示失败的证据。人物在远景中难以看清时，可以保留尘土等连续微小运动线索，但不能把静态盆景误称为完整骑行。

## 07 · 同一海湾的另一季 / seasonal-gate

**命题：走过一扇门，时间变了，地点仍可认出。** 季节边界位于门洞，而不是随镜头给整张画面渐变调色。

未来制作设计统一为早夏进入薄雪冬季，与当前概念图的季节方向一致；这项修订不改变历史实际提交提示词，也不表示视频已经验证。首图从骑手后侧接近古老石拱门，门外绿草与白黄花，门内只斜露覆薄雪的草坡和松枝；同一条土路穿过门洞，主体路面裸露可骑，门框厚度和基座明确。海湾不封冻，海湾轮廓、岛礁、拱廊与光照方向保持对应。同一红衣黑短裤骑手、头盔、背包和双轮车跨门保持不变，季节差异仅由门后环境表达。

目标仍为10秒：0–2秒接近拱门；2–5秒骑手沿可骑的连续土路越过门槛；5–8秒相机随后穿门并轻转，薄雪草坡衬托同一组空间锚点；8–10秒人物接地续骑，门框退出侧边，保留冬日海湾。两侧斜阳同向，冬侧加入雪面柔和反光与浅蓝阴影，声音意图是轮胎压土、风声与松枝轻动。门柱提供真实遮挡，不用换人、换车或换装掩盖跨段差异。

首轮先做720p、5秒无骑手的固定门与地理小样，保留一处岛礁、一个拱廊和连续土路作对照，验证薄雪只在门内、路面仍可骑与光向一致。局部季节边界成立后再加入骑手穿门，分开验证身份与接地。若门后变成另一片海湾，就丢失“同地另一季”；若薄雪扩散到门外、全画面同时变色或积雪堵路，均需返修，不能用全屏溶解或人物替换掩盖。

## 共同验收与返修顺序

| 检查层 | 需要看到的证据 | 不能据此冒充的结论 |
| --- | --- | --- |
| 景观价值 | 开头、变化后与结尾各有具体观看内容 | 一帧漂亮就代表整片成立 |
| 空间摄影 | 位移、遮挡、近远视差或可读的实体/倒影同框 | 数字缩放等同真实移动 |
| 单一机制 | 事件前状态、改变过程、结果能被辨认 | 任何奇怪变形都算有意荒诞 |
| 人物控制 | 衣物车架一致、手脚接触、双轮与路线连续 | 同色衣服就证明同一人物 |
| 时间完整性 | 行动有结果，结尾仍能理解下一步 | 首尾图自动保证中间轨迹与时刻 |
| 制作记录 | 保存实际输入、生成原件、编辑版本和审片依据 | 概念设计等同模型已执行或已看参考视频 |
| 声音 | 实际播放听验后再记录内容与接点表现 | 有音轨或波形就等于听觉自然 |

建议先从悬崖长卷验证基础摄影，再测试门中海或花种载岛的单一空间事件；倒影先行与踏板唤醒城市依赖精确可读时序，可作为后续较难试验。这个顺序是设计与风险判断，没有成功率、市场效果或流量回报承诺。

每轮先修改一个决定性偏差：路线不成立就改首图和机位，事件不可读就减动作与实体数量，时间不合就调整目标或编辑结构；不把加清晰度、加时长和加特效作为通用修复方式。
