# 子项目目录

[返回总索引](../README.md#项目索引)

这里保存独立研究项目。通过仓库根目录的 `npm run project:new -- ...` 创建，目录依次为 `001-slug`、`002-slug` 等。

每个项目包含：

- `README.md`：项目介绍、原仓库、研究目标、图片说明、运行方式与结论。
- `research/notes.md`：阅读与复现记录。
- `assets/images/`：项目截图和演示图片。
- `app/`：按需添加的实践代码或 Web 应用。

具体项目列表与研究进度以[总索引](../README.md#项目索引)为准。
