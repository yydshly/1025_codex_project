## 这次研究回答什么

- 为什么同样有蓝天、海湾、奇幻建筑与骑车人，生成结果仍像一张在动的壁纸？
- 如何用接近、追随、转弯和近远视差，让相机真正带观众穿行空间？
- 如何让一次动作揭示新景观，并包含发生、落地和继续前行？
- 哪些效果来自生成，哪些来自剪辑变速，哪些仍然没有做好？

页面包含参考分析、沟通过程、试验对照、创作原则、可复制提示词、验收标准与七个新方向。四个通用模板是研究后新整理的内容；A/B 的历史实际提示词可在影片参数中查看，七张新图的实际指令可在“首图”标签页折叠区查看、复制，数据分别保存在 `app/data/execution.js` 和 `app/data/concept-generation.js`。

## 已经得到的结论

**美景是主舞台，人物负责带路，动作应该换来新的观看收获。** 骑行、跳跃、蓝绿橙配色、HDR、60 fps 或某个视频模型都是可选手段，不是这类作品的固定配方。

最初的固定广角、低运动方案保护了构图，也限制了摄影路径。随后提高到 1080p 增加了清晰度，但没有自动修正镜头与动作。取得完整参考后，对约 6.97 秒、60 fps 的时间过程做分析，才明确了接近主体、地形遮挡、追随转向与近远视差的作用。

此前的完整跃岭试验使用两段 Seedance 2.0 视频，按实际动作重新剪接：A 已自行完成起跳和落地，因此舍弃 B 开头重复的腾空与落地；A 腾空中段做了 2× 变速，最终在约 4.083 秒处明确换机位。成片有可辨认的“接近—跃起—景观打开—落地—继续前行”，但仍有地理与色调跳变、跳得过高、起跳蓄力与落地吸震不足等问题。它是研究样片，不是精确物理控制的证明。

随后《悬崖长卷》用两条 Kling 4.0 源片验证至少10秒的真实拼接：A的真实末帧作为B首图，最终取A前5秒与B全部6.041667秒，在5.000秒硬切。人物、脚踏相位和主要地理基本承接，但共享边界图仍不保证相同速度或完全相同的下一帧；接点有轻微重绘，B后段明显拉远。这个结果验证了本次双片制作与接缝审查流程，不代表原10秒分镜每项都精确达成。

## 理解、价值与能力

网页新增[理解与能力总结](app/index.html#understanding)，引导页继续使用专门生成的 [overview-v1.png](assets/images/overview-v1.png)，保留原图并在旁边补充11秒进展。动态奇观由世界与首图、人物行动、摄影路径、环境响应、时间剪辑、审查迭代共同构成；图生视频生成时序画面，并不意味着已经重建可交互3D世界。

当前做到的是图像到动作／摄影，再到真实双片拼接、接缝检查和证据归档。价值在景观探索体验与可复用导演方法；漂亮图、模型版本和分辨率都不自动保证效果。首尾接力仍需检查姿态、脚踏、速度、路线与光色，不能称精确骨骼或路径控制、自动长片系统或通用模型排名。

近期可试验系列景观旅程和品牌／文旅概念样片；动作摄影模板与首尾接力已有手工方法，仍待产品化；互动创作工作台是待建假设。这些方向需要分别验证体验、可复用性和修正效率，不是已上线商业成品，也不承诺收益。主站提供简明连续性方法、失败信号，以及首图／视频提示词骨架，再链接到完整流程和可复制模板。

## 悬崖长卷 · 11秒双片拼接实测

[观看当前拼接版](https://yydshly.github.io/1025_codex_project/013-scenic-motion-lab/?film=coastal-scroll-splice-v1#screening) · [制作设计](research/coastal-scroll-splice-v1-design.json) · [实际剪辑记录](research/coastal-scroll-splice-v1-edit.json) · [实际接缝对照](assets/images/coastal-scroll-splice-v1/actual-seam.jpg)

两条源片均为Kling 4.0、720p档原生1284×724、24fps。A任务1044781原有121帧；第120帧作为B任务1044794的实际首图，交付中从A剪除这帧，以免相似边界姿态重复。成片取A第0–119帧（5秒）与B第0–144帧（6.041667秒），共265帧、11.041667秒，在5.000秒真实硬切；两源仅归一至1280×720，没有循环、定格、变速或溶解。

接缝前后人物位置、尺度、朝向和脚踏相位基本承接，未见明显动作倒回或地理跳位；人物与花草仍有轻微重绘、柔化。A仍略微靠近，B后段明显拉远并把注意力留给海湾，不能称严格匀距、精确速度匹配或完全无缝。B确认实际180积分，A最终费用未知，实际总额不补推。音频未听验，数值检查不等于听觉通过。B原件与结果见[B交付记录](research/coastal-scroll-kling4-b-v1-delivery.json)，声音检查范围见[音频记录](research/coastal-scroll-splice-v1-audio-check.json)。

## 悬崖长卷 · 历史5秒模型对照

[观看 Seedance 2.0 对照](https://yydshly.github.io/1025_codex_project/013-scenic-motion-lab/?film=coastal-scroll-seedance2-v1#screening) · [准确运动提示词](research/coastal-scroll-trial-v1-prompt.txt) · [设计与实际参数](research/coastal-scroll-trial-v1-design.json) · [交付与审片](research/coastal-scroll-seedance2-v1-delivery.json)

[观看 Kling 4.0 新版](https://yydshly.github.io/1025_codex_project/013-scenic-motion-lab/?film=coastal-scroll-kling4-v1#screening) · [新版交付与审片记录](research/coastal-scroll-kling4-v1-delivery.json)

Kling4.0新版也已交付：720p档原生输出实际1284×724，121帧、24fps、5.041667秒，保留原速与音轨。相较本次Seedance样片，人物尺度更稳定，近花石快移、远海岸慢移的视差可辨认，风景仍占主导；约0.75–2.5秒轮胎被花草遮挡，全程沿路接地尚未严验。网页预估150积分、提交后余额相应减少150；任务查询成本字段N/A，最终消耗仍未确认。声音未听验，两条具体样本也不能构成模型普遍排名。

采用现有概念图作视觉参考，设计右向骑行、侧后方平行跟拍、近花石快移与远崖慢移。原片体现了横向跟拍和视差，但约0.25–1秒跨向路外花坡、0.5秒附近短暂浮起，机位也逐渐靠近；不能把“有5秒视频”写成完整方案已验收。原片保留原速，无剪辑、变速或插帧；视频轨121帧、24fps、5.041667秒，含音轨文件5.088秒，实际75积分。声音未听验。

用户随后要求新版模型优先。当前官方自动生成工具的公开代码尚无Kling4.0/Seedance2.5注册项；因此从现有ChatArt网页核实新版、准备图片与准确指令，用户登录现有账户后提交任务1044781，并通过官方查询工具取回原片。过程见[新版模型执行记录](research/coastal-scroll-higher-model-plan.json)。原Seedance2.0和新版任务的漫长等待均不能当成生成失败，也不能把网页的新版入口等同于旧工具已支持。没有接入Runway、没有提交KlingV3或额外的Seedance2.5任务。

## 本地运行

需要 Node.js 22+ / npm 运行 `check`，以及 Python 3 提供 `serve` 的静态服务。从研究总库根目录进入本项目运行：

```powershell
cd projects/013-scenic-motion-lab
npm run serve
```

本地入口为 [http://localhost:4333](http://localhost:4333)，静态站点根目录是 `app/`。这是本机预览地址，不是公开演示。

验证项目与外层索引：

```powershell
# 本项目目录
npm run check

# 外层研究总库
cd ../..
npm run check
```

`check` 验证网页及资料组织，不替代对视频动作、画面连续性和声音的审查。首轮浏览器实测已覆盖播放、筛选、搜索、复制、下载、深链接与键盘交互；七张概念图均正常加载为 1672 × 941，390 和 1280 像素视口无横向溢出，未发现新的控制台错误。首轮完整研究 JSON 导出验证包含当时的概念、视频及概念图实际生成指令；后续短样和拼接版继续纳入当前目录，历史检查范围见[本地验证记录](research/local-verification.json)。
