## 对样片的理解

模板分为 scene（给场景与默认参数，按简报制作）和 example（带有具体风格要求的作品提示）。样片是特定制作输入的结果，不表示整个工具被限定为单一风格，也不保证更换主题后得到相同完成度。

五类分组是本研究为了选型而整理，不是上游原始分类。24 个方向中 4 个没有附视频，不使用虚构预览填充。20 段原始预览均约 15 秒；16 段无音轨，4 段含音轨。默认成片时长与预览时长分别展示。

官方验证标记为 6 项 pass、18 项 partial。pass 也应结合原始 notes 阅读，例如动效示例在测试时跳过了未配置的配乐与音效。知识讲解示例的月相光照经过两轮人工指出才修正；不能把示例存在推断为自动制作始终准确。

## 与之前研究的关系

Short Video Factory 侧重自动混剪；AI YouTube Shorts Generator 侧重按转录选段；我们实际制作过的 Canvas / SVG 动效由代码渲染；剪映无头库配 Skill 侧重适配剪映工程和引擎。BaoCut 的共同点很多，主要架构差异在于提供自己的工程、编辑器与统一运行时，并将工具调用、人工修改、版本与撤销纳入同一套系统。

单看 SKILL.md，价值是操作知识和制作规范。判断效果优势需要同素材、同目标的实际对照，目前没有开展此对照。

## 展示与验证

静态 HTML / CSS / JavaScript，目录由本地 JSON 读取，视频使用浏览器原生播放器。Node 服务绑定 127.0.0.1，支持 HEAD 和 Range 请求；不含外部 API 或账号功能。89 个原始文件通过哈希检查，20 段视频均完整解码成功。

初次预览中发现 Windows 路径尾部分隔符使合法资源被拒绝，已用 path.resolve 归一化根目录；首页随后返回 200，媒体范围请求返回 206。浏览器实际验证分类、搜索、空结果、无预览提示、制作记录、动效与讲解视频播放、时间进度跳转。查看范围与证据写入 verification.json。

## 2026-10-26 · 实现路径补充

后续要求明确区分代码动画、AI 生成和已有素材。逐条通读 24 份 verification.notes 与 prompt.md 后，按画面主要来源归为 14 个代码画面、5 个 AI 静图加代码运镜、5 个已有素材加剪辑。每条分类都保留一段与原记录逐字匹配的证据，数据独立放在 app/implementation.json。

重要修正：电影感场景只有一张生成图，雾和光没有动态；游戏与故事样片的动作主要来自静帧运镜。舞蹈模板的文字要求使用视频生成，但实际因能力缺失改成代码机器人与节拍时钟。软件演示和分步教程是虚构 UI 的代码动画，未记录真实录屏。热点快评虽允许搜索素材，实际记录采用原创代码图形。不能依据模板要求给实际预览贴上“AI 视频生成”标签。

固定版本 video-production/SKILL.md 明确写明没有视频生成能力，并说明图片本身静止、运镜需另行实现；它还提供 HTML / Canvas / SVG 代码包和实时预览流程。记录中的历史样片大多先用本机脚本渲染成片段，导入时间线进行组合。两种路径分别标明，未推断它们用了相同的底层渲染库。

网页补充制作路径总览、按做法筛选、逐条画面/动作/AI/声音/时间线分工、差异与限制、原记录摘录及固定提交链接。统计按视觉路径，AI TTS 不会把代码画面误归为视频生成。此轮依旧未安装或运行 BaoCut。

## 2026-10-26 · 阅读与试做引导补全

用户要求继续优化和补全。本轮将详情拆为三个页签，加入连续浏览、音轨/预览条件筛选、原始提示页内阅读，以及筛选、场景和页签的 URL 恢复。新增 guide.json：三条路径的改动位置、准备材料、先做小样和验收点，加上 24 条针对具体场景的注意事项；均标注为本研究建议，未新增本机制作记录。

教学示意用同一个 6 秒时间轴展示三种不同的变化：程序计算图形位置、静图改变取景、按剪点切换镜头。小球只用位置公式，不声称物理模拟；静图使用官方电影感场景封面；A/B/C 为抽象镜头标记，不播放任何原视频。没有把教学示意当作 BaoCut 生成效果。

为降低本地服务依赖，增加构建脚本，将固定目录、研究注释、复现建议和 24 份原始提示打成 data.js，使用普通 defer 脚本加载；原始文件继续不改动。内置浏览器阻止 file: 协议，未采用其他浏览器或控制机制绕过；直接文件访问未完成浏览器验收，HTTP 模式继续可用。

浏览器已检查时间滑块到终点时的三处同步变化、详情键盘页签、原始提示展开、下一条保留页签、刷新恢复具体样片且不自动播放、4 个含音轨样片，以及“已有素材 + 含音轨”的 2 个交集。复制入口控件已实现，但没有为自动测试改动用户剪贴板。
