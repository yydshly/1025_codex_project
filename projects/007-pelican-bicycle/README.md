# 007 · 鹈鹕的单车日和

一只戴着小帽子的鹈鹕骑车经过海边：这是一个用原生 SVG、CSS 和少量 JavaScript 制作的轻量互动动画。

[在线体验](https://yydshly.github.io/1025_codex_project/007-pelican-bicycle/) · [返回总索引](../../README.md#项目索引) · [实现笔记](research/notes.md)

## 体验

打开页面即可看到车轮转动、骑手轻轻起伏、云朵和花草随风摆动。页面提供暂停和调整速度的按钮，并适配手机屏幕；系统启用减少动态效果时，页面会从暂停状态开始。

## 本地运行

无需安装依赖或构建。直接在浏览器中打开 [app/index.html](app/index.html)，即可体验。所有插画均为项目内的 SVG，无需联网加载资源。

## 实现说明

画面由 SVG 绘制，车轮、曲柄、骑手和背景使用 CSS 动画，按钮通过 JavaScript 控制动画的暂停和速度。动画以插画表现为主，并非精确的自行车机械运动模拟。
