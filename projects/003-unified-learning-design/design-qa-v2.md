## v2.0 互动书验证

阅读流程为打开封面，沿着种子、幼芽、交互植物和主题迁移四章探索，必要时从目录跳转或回看前页。

| 环节 | 实际结果 |
| --- | --- |
| 打开和合上 | 鼠标点击与 Enter 可打开，合书后回到封面 |
| 前后翻页 | 翻页使用双面纸页，向前为 forward、向后为 backward；页码对应 01—08 |
| 章节导航 | 章节书签和目录可跳转；点击当前目录项也会关闭目录 |
| 边界状态 | 第一章上一页禁用，第四章下一页禁用 |
| 图文操作 | 0 和 100 展开程度更新数值、插画与讲解，预设可以选择 |
| 键盘 | 左方向键可向前回看；滑块上的 Home 调整数值且不改变章节 |
| 连续状态 | 从第四章翻回第三章，展开程度仍为此前选择的 100 |
| 主题预览 | 机械与星图切换后，场景与解释同步变化；主题动效可暂停 |
| 排版 | 第三章说明文字与页脚无重叠，桌面实测二者相隔约 48 像素 |
| 窄屏 | 390 × 844 预览中，上下排列书页，目录与 20% 预设可用；内容宽与滚动宽均为 375 |
| 浏览器日志 | 所验证操作过程中无 console error 或 warn |

开合与翻页的平面、透视、页边和纸张阴影由 CSS 实现，插图由 SVG 绘制。手机使用顺序排页和简短切换，未沿用桌面的双页旋转。减少动态效果偏好在实现中有专门处理。

## v1.1 方法总览验证记录

以下记录对应保留在 `app/handbook.html` 的原网页手册。

## 完整使用流程

用户进入网页，阅读八步方法，操作筛选工作台，浏览三类扩展方向，然后填写主题信息，生成并下载规划提纲。网页是纯前端页面，使用固定教学数据和用户当前输入，不依赖模型、数据库或业务 API。

## 验证结果

| 环节 | 实际结果 |
| --- | --- |
| 页面与资源 | HTML、CSS、JavaScript 和文档请求均返回 HTTP 200，内容类型正确 |
| 方法切换 | 第六步显示对应标题和 06 / 08；从第八步点击继续可回到第一步 |
| 初始筛选 | 阈值 18，结果 B、C、D，共 3 条 |
| 修改条件 | 阈值 24，结果 C、D，共 2 条，讲解包含等于阈值的情况 |
| 空结果 | 阈值 31，没有记录满足条件，讲解解释空结果并保留原始卡片 |
| 输入边界和重置 | 滑块最小值 0 时保留 4 条；最大值 36 时保留 0 条；重置回到 18 |
| 迁移题 | 选择错误与正确答案分别得到原因说明，正确结果为 3 条 |
| 扩展分类 | 主题 6 项、表达 3 项、制作 3 项；详情可以展开 |
| 分类键盘操作 | 左右方向键与 Home 可切换，选中状态和面板标题同步 |
| 表单校验 | 仅空白字符的主题会被拒绝，提示填写具体内容 |
| 提纲生成 | 输入“节奏”和受众、目标，输出包含对应内容的规划 |
| 下载文件 | Markdown 下载成功，读取文件确认标题为“节奏互动体验规划” |
| 浏览器日志 | 已检查的操作过程中，页面无 console error 或 warn |

## 验证范围

HTTP 预览和本地导出流程已验证。复制按钮在剪贴板不可用时提供选中文本的替代方式；没有请求剪贴板额外权限。尚未开展目标受众的教学效果测试，也尚未部署到公网。

内置浏览器仅允许 HTTP 和 HTTPS，未验证直接打开本地文件的方式；预览请使用 README 中的本地服务命令。
