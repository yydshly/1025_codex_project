## Research Paradigm

采用面向经验研究的实用主义证据综合：保留各研究可观测的比较和不确定性，用统一字段比较其可比与不可比之处。主问题问的是已报道效应在条件之间如何变化，因此选择研究内比较加跨研究结构化叙述；不通过模型评分或多数表决代替效应证据。

## Method

**形式：** 有检索记录的叙述性证据综合，结合结构化文献矩阵与跨研究比较；不进行统计合并，不声明完成 PRISMA 系统综述或正式创新性查证。

**与主问题的对应：** 先回答每篇研究“比较了什么、观测到什么”，再描述生命阶段与暴露条件下的分布，最后区分机制观察与机制推断。来源数量少或异质性大时保持逐研究展示，不为了得出统一结论而拼接不同 PFAS、阶段和终点。

## Data Strategy

### 数据来源与检索计划

数据为公开原始论文及其补充材料。计划优先使用 PubMed、出版商原始页面和可访问的全文库，并用 Crossref 或其他书目索引确认 DOI、题名和版本；后者的存在性核验不能作为全文支持或创新性证明。实际使用的每个服务、检索式、日期、可见结果范围及访问失败均需在 Phase 2 记录，本阶段不声称这些检索已执行。

检索概念组：

```text
(zebrafish OR "Danio rerio")
AND (microplastic* OR nanoplastic* OR polystyrene OR polyethylene)
AND (PFAS OR PFOS OR PFOA OR "F-53B" OR perfluoro* OR polyfluoro*)
```

同时执行较窄的化学物种/颗粒材料组合，并在支持的检索器上尝试 coexposure / co-exposure / combined toxicity / mixture / sorption / bioaccumulation 等补充词；不强制所有查询都包含这些词，以免遗漏只在全文描述联合处理的研究。中文同义词可作为补充检索。对最相近原始研究和综述的参考文献、被引文献开展有记录的追踪，凡未能访问的服务明确标记，不假设已覆盖。

时间范围固定为 2015-01-01 至 2026-10-29。计划无国家限制，实际语言覆盖依可访问材料如实披露。种子 DOI/PMID 仅是定位起点，不构成封闭样本，也不是预先认定的有效证据。

### 分层记录与纳入规则

1. **核心比较材料：** 原始斑马鱼共暴露研究，至少可辨认共暴露与同条件 PFAS 单独暴露；能读取支持相应比较的结果部分。
2. **受限线索：** 只有摘要、部分正文或对照不完整，登记实际可见结论和缺失字段；不用于详细机制判断或研究方法质量评分。没有 PFAS 单独暴露组时不能回答本主问题的方向比较。
3. **范围外背景：** 其他物种、其他共污染物、综述或吸附实验；若保留，单独标记用途，不混入核心结论。

记录排除或受限理由；不为满足来源数量而放宽到不同物种/不同污染物。出现同一实验的多篇报告时建立关联，避免按文章数重复计算独立证据。

### 计划提取字段

| 字段组 | 需提取的信息 | 缺失处理 |
|---|---|---|
| 文献身份 | DOI/PMID、题名、作者、年份、版本、原始研究/其他类型 | 核验失败保留未解决状态 |
| 阅读范围 | 全文、方法/结果章节、摘要；URL、页码/表图/段落定位 | 不把摘要当全文已读 |
| 群体与单位 | 品系、年龄/生命阶段、性别、鱼/胚胎数、实验缸/孔及独立重复 | 未报告或未读取分开记录 |
| 颗粒 | 聚合物、原文 micro/nano 标签、实测尺寸与分布、形状、表面功能化、老化、分散状态 | 保留原始单位，不自行猜测尺寸或统一标签 |
| PFAS | 明确化学物种、混合物/配方、纯度（可见时）、剂量 | 不把 PFOS/PFOA/F-53B 合成一个物种 |
| 暴露方案 | 水相/饮食等途径、时长、同时/先后处理、预吸附、介质、更新方式、名义/实测浓度 | 无实测值时不声称真实暴露浓度已确认 |
| 对照 | 空白/溶剂、塑料单独、PFAS 单独、共暴露及对应剂量 | 缺少的比较明确列出 |
| 终点与结果 | 生存、发育、行为、组织/器官、生化/分子等原文终点；时间点、效应大小/变异、统计比较 | 仅有方向或摘要表述时按该信息层级记录 |
| 机制与来源 | 水中游离浓度、吸附、组织负荷、标志物、干预/时序；作者表述与读者推断 | 不把组学富集等同因果机制 |
| 报告与局限 | 随机化/盲法、独立重复、统计单位、多重比较、伦理声明、作者局限 | 全文未读时不根据未见信息断言作者缺失 |

## Analytical Framework

### 1. 研究内比较先行

每个结果行采用 `研究 × 实验条件 × 终点 × 时间点` 的单位。首先找同实验中的 PFAS 单独暴露组，再判断共暴露变化；相对空白组的变化另列。不同剂量、生命阶段、暴露时长或采样时点不能直接替换比较。

### 2. 效应方向编码

| 编码 | 含义 | 使用边界 |
|---|---|---|
| enhanced | 共暴露的同一不良终点较对应 PFAS 单独暴露更强 | 写明终点和统计比较；有毒性意义不明的生物标志物变化应单独描述 |
| attenuated | 共暴露的同一不良终点较对应 PFAS 单独暴露更弱 | 不自动解释为总体保护或安全 |
| no_clear_difference | 该比较未检出明确差异 | 不写成等效、完全无效应或不存在相互作用 |
| mixed | 不同终点、剂量或时间点的方向不同 | 尽量拆为多行，混合标签仅用于论文层展示 |
| not_resolvable | 缺少可比对照、结果数据或可见材料 | 不补推方向 |

“增强/减弱”不自动等于“协同/拮抗”。只有原研究使用清楚的加和参照模型、相互作用项或其他明确的联合效应方法，并能核查其输入与适用性时，才另行记录 interaction 结论；否则报告 `interaction_not_established`。作者使用了协同等词但可见证据不够时，区分“作者命名”与“本次可核验证据”。

### 3. 条件分层比较

先按 PFAS 化学物种和生命阶段分组，再考察颗粒材料/尺寸/表面状态、暴露途径/时长、预吸附与名义或实测剂量。相同方向并不意味着相同机制；不同研究方向相反也可能来自终点或比较条件不同。无法分离的条件差异表述为候选解释或混杂，不声称已识别因果调节因素。

不将每个分子指标计为独立研究，不按“显著结果的篇数”计算总体危险率。保留零结果和反方向证据；正文结论的分母应能追溯至明确的研究集合。

### 4. 机制证据分层

- `hypothesis_only`：作者讨论或综述引用提出的可能机制。
- `associated_markers`：与毒性同时变化的生化、转录、组学或组织标志物。
- `direct_exposure_measurement`：在相应实验中直接测得的水相浓度、颗粒行为或体内 PFAS 负荷；用于支持暴露路径，但其本身仍不证明毒性介导关系。
- `causal_support`：有相应干预、时间顺序、路径阻断/救援等设计，能支持特定链条；须具体说明支持哪一步及替代解释。

这是本项目的提取编码，不是经过验证的通用质量量表。各层不要求互斥，可并列记录。不能把分子变化越多解释为机制证据越强。

### 5. 新颖性与缺口表述

后续搜索要比较最近综述和最相近原始研究：已有研究回答了什么、当前整理新增哪些可追溯比较。检索未找到只能写为“在已记录检索范围内未发现”，不能写成“首次”“无人研究”或“证明创新”。“缺少全文/检索未覆盖”与“领域缺少研究”分开。

## Validity Criteria

| 风险 | 本设计的控制方式 |
|---|---|
| 化学物种、颗粒或生命阶段被混用 | 主表保留原始字段，分层描述，跨层推论显式标注 |
| 对照不同导致虚假增强/减弱 | 只在同实验匹配 PFAS 剂量、时长与终点后编码 |
| 把标志物变化当有害或保护 | 按原始终点解释；方向未必具有明确不良含义时不强行归类 |
| 同研究多终点造成伪重复 | 保留研究/实验关联，不把终点数量当独立证据数量 |
| 摘要信息被升级为全文结论 | 阅读范围与证据定位单独列，细节缺失保持未知 |
| 选择性纳入支持预设叙事的论文 | 搜索含减弱/无差异的候选，登记受限/排除理由，保留反证 |
| 书目信息真实但引文不支持论断 | 每个关键论断回查方法/结果/讨论的具体位置，区分直接结果与推断 |
| 通用医学证据等级误用到鱼类毒理 | 采用“研究设计”和“对具体论断的适配性”两轴，按下述字段检查，不机械授予 RCT/临床等级 |

源质量检查参考上游的两轴思想，但其等级表并未提供专门的水生毒理验证量表。本项目记录对照与暴露表征、实验单位/独立重复、随机化与盲法报告、统计比较、结果报告完整性、利益冲突及伦理声明，不编造数值综合质量分或声称经过验证。仅在实际阅读范围内提出局限，并注明是作者承认还是读者推断。随机化、盲法“未报告”只有在已检查相关全文部分后才可记录；摘要未提及应标“未评估”。

## Limitations by Design

- 这是一轮公开可达文献的叙述性综合，不能声称穷尽全部数据库、语言或未公开数据。
- 尚未确认种子研究是否全部有可访问全文；若只有摘要，结论将受限于摘要层级。
- 论文间暴露条件、终点和实验设计可能不兼容，不承诺统计合并或单一方向结论。
- 本项目不能核实原始实验实际执行、原始数据真实性或结果可复现性。
- 不从实验室名义剂量直接推导自然环境风险或人类健康风险。
- 当前没有独立双人筛选、盲评一致性测量或跨模型校准；后续如开展需另留记录。

## Ethics and Reporting

本任务不招募人类参与者、不接触个人可识别数据、不新增动物实验。原论文的动物伦理说明只按实际可见材料记录，文献报告存在不等于本项目独立认证其合规。避免复制长篇原文；结论链接到原始论文并披露 AI 参与检索、整理和写作。

报告标准选择 **Other：透明的叙述性证据报告**。最低交付包含问题范围、实际检索日志、来源清单及阅读范围、研究内比较表、机制证据等级说明、反例和局限；不展示未经实际筛选产生的 PRISMA 计数，也不声称完成 PRISMA 或 GRADE。
