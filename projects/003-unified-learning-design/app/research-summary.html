先用四个问题认识这份研究

效果、能力、原理与价值。

效果

一本可操作的三维物理书

纸页可以翻动和掀开，轨道、弹簧与能量瓶从书面立起，文字和实验处于同一空间。

能力

读、看、听、预测和验证

三课样章支持参数操作、预测反馈、MiniMax逐句导览、文字放大、七段连续阅读及暂停恢复。

原理

由同一实验状态协调表达

Three.js绘制空间书页和器材；明确假设的物理模型计算状态，再驱动数值、画面、镜头和讲解。

价值

留下可运行的样章与设计方法

为互动教材、原理说明、实验平台和主题展览提供复用参考。预期学习价值仍需受众验证。

01 / 我们最终理解了什么

价值来自持续关联。

最初被三维效果吸引，进一步发现：真正值得借鉴的是打开载体、按页进入、围绕同一主题持续展示，让每一段文字都能关联一个对象、一种操作和一次解释。

01

载体建立进入方式

书页、档案册、工作台或标本册，让用户知道自己在怎样的环境里探索。打开、翻页、掀盖等动作成为内容的一部分。

02

章节保留前后关系

同一对象、颜色和问题持续出现。每章写清：从前面保留什么、增加什么发现、带到下一章什么。

03

表达共享同一状态

文字说明、镜头、物体、公式和反馈指向同一个时刻。改变条件后一起更新，返回时保留上下文。

04

操作推动理解

用户可以先预测、再改变条件、观察结果和解释原因。用一个新例子检验能否迁移理解。

对学习者把抽象关系变成可观察的变化

有对象可找、有条件可改、有结果可比较。

对讲解者把注意力、证据与解释接在一起

说到什么，就能指出当前对应的对象和状态。

对创作者把一页体验积累成可复用规则

以统一状态协调表达与流程，再根据主题选择媒介；当前硬编码物理样章仍需针对新主题重新适配。

以上是设计价值与产品假设。当前已有交互与实现证据；是否提高学习效果，仍需目标受众试用、原因解释与迁移任务来验证。

03 / 从样章提炼通用方法

围绕一个理解目标，组织所有表达。

先写清“谁最终能解释、判断或完成什么”，再选择载体与媒介。知识关系决定表现方式，章节推进决定交互节奏。

六种表达，共享一份状态。它们是相互对应的设计职责：参数、数值模型、画面、镜头、语音与返回位置应彼此一致。

  • 内容

    明确关系

    对象、条件、变化、结果

  • 视觉

    让关系可见

    形状、空间、时间与数量

  • 讲解

    指向当下

    当前对象、当前状态与原因

  • 操作

    改变条件

    明确可改项与固定项

  • 反馈

    解释结果

    变化、证据与预测对照

  • 检验

    换例子判断

    能否用同一关系作出判断

每个场景，一次完整理解过程

提出问题 → 作出预测 → 看演示 → 亲手操作 → 对照反馈 → 迁移检验

预测用于形成判断；反馈应让人知道为什么。比较时先只改一个主要条件，基本关系清楚后再增加组合条件。

每个章节，三句承接关系

保留什么
同一个对象、问题、参数或操作规则。
增加什么
新的关系、条件、证据或观察角度。
带走什么
下一章会用到的发现和未解问题。
对象身份稳定颜色含义稳定动作含义清楚解释随状态更新回退能恢复上下文声音与动效有替代入口

空间结构适合旋转、拆解和剖面；规则判断可用二维卡片；时间过程可用时间线与声音；观点与证据可用材料对照。3D 是一种表达选择。

真实测量的取舍

06 / 可以形成哪些产品

从一套效果，走向不同的使用场景。

下面整理的是后续产品思路与选题方向。当前阶段以理解和复用为目标，保留样章、方法和证据，等待具体产品需求。

01 / 学习者

个人学习平台

阅读、操作、疑问和进度集中在同一个主题里。

02 / 教师

课堂演示平台

编排讲解，收集预测，再演示、讨论和对照证据。

03 / 探究者

数字实验记录本

保留条件、测量、图表和结论，比较多次实验。

04 / 作者

互动内容制作工具

把段落绑定到实验，配置参数、镜头、语音与挑战。

05 / 产品团队

产品原理说明

边介绍边拆解，观察部件如何共同形成运行结果。

06 / 展馆

科普与主题展览

大屏组织主题，工作台支持观众分步动手探索。

07 / 实验室

虚实结合实验台

屏幕指导实体操作，将真实测量接回图表和解释。

08 / 跨主题创作

连续主题体验库

以成熟场景为起点，积累适配不同主题的表达规则。

换主题时，保留方法，重新选择媒介。

每次迁移都需要新的内容依据、模型边界与用户检验。当前样章尚未成为可直接换题的通用平台。

物理

条件 → 运动 → 能量

改变高度或阻力，观察并解释能量去向。

适合：三维实验、数值与图表
编程

代码 → 执行 → 结果

改变筛选条件，逐条观察判断与数据保留。

适合：二维卡片、流程、执行轨迹
音乐

乐谱 → 时间 → 声音

调整四格节奏，比较排列与速度的区别。

适合：时间格、播放指针、试听
历史

史料 → 证据 → 解释

并列材料，追溯来源，比较不同解释。

适合：档案桌、地图、时间线
工程

部件 → 协作 → 系统

拆解装置，理解局部变化如何影响整体。

适合：分层、剖面、结构联动
审美创作

选择 → 差异 → 表达

只改一个构图关系，描述感受与创作意图。

适合：前后对照、重组与试听
流程决策

输入 → 约束 → 路径

改变情境条件，比较规则、结果与取舍。

适合：流程图、情境卡、路径对照

07 / 以后怎样拿来用

留下三层资产，按真实需求再展开。

Ⅰ

实现资产

三维书页、器材与镜头；阅读与导航；状态驱动的实验；配音导演；暂停、回退和上下文恢复。

使用前检查：新的内容与交互规则是否匹配。
Ⅱ

方法资产

理解目标、关系拆解、统一环境、表达规则、章节承接、预测与反馈、迁移任务与验收。

使用前检查：每个操作究竟帮助理解什么。
Ⅲ

产品思路

教材与实验平台联动；按需讲解；探索记录；多种布局；个人、课堂、展览与创作工具。

使用前检查：谁在什么环境里解决什么问题。

遇到相关产品时，从一个小场景重新启动。

  1. 确定目标受众与理解目标写清谁最后能解释、判断或完成什么。
  2. 选关系与载体决定用书、工作台、时间线、档案或实验室。
  3. 走通一个完整场景一个问题、主要操作、结果解释和迁移任务。
  4. 试用并记录理解断点观察能否解释原因、预期变化、处理新例子。
  5. 再扩章与提取复用第二个主题出现真实重复需求后，再提取组件和配置。
