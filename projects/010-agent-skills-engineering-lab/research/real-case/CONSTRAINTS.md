# 本案例质量约束

日期：2026-10-28。适用：010 研究回顾入口。规则的通过与失败见 [verification.md](verification.md)；本文件不是已经执行的检查结果。

## 共同底线

1. 数据输入限根 `projects.json` 与其中登记项目的 README。不得递归读取私人目录、日记、缓存、备份或 ReflectFlow 路径。
2. 登记和源文档只读；索引是派生产物，可重建，不改变项目编号和原结论。
3. 文本必须区分“收录”“已总结”“已实测”“已发布”，避免把研究状态升级为没有证据的能力。
4. 用户输入按文本处理；导入先整体校验再写入，失败与冲突不得破坏原笔记。
5. 不为获得通过而跳过测试、删除断言、放宽长度限制或改变错误语义。合理需求变化要同步规格和说明原因。
6. 不覆盖其他未提交工作；本轮没有 Git 提交、推送、线上发布或真实格式迁移。
7. 不能把未执行的动作、预期结果、教学场景标成实测。

## 规则怎样变成检查

以下命令均在 010 子项目目录执行，除非单独说明。

| 维度 | 判定要求 | 检查命令或动作 | 时机与失败处理 |
| --- | --- | --- | --- |
| 来源完整性 | 登记集合、文件哈希、段落内容与行号对应 | `node scripts/build-recall.mjs --check` | 源文件或生成器变更后；不一致先重建或修复 |
| 行为正确性 | 查询、筛选、规范化、导入合并及错误路径符合规格 | `node --test tests/recall.test.mjs` | 核心逻辑变更后；失败不得声明功能完成 |
| JavaScript 语法 | 当前修改的 JS 可解析 | `node --check app/recall-core.js`；`node --check app/real-case-data.js`，以及本轮页面脚本 | 对应文件变更后；失败先修复再浏览器验证 |
| 浏览器闭环 | 搜索→来源→笔记→刷新→导出/粘贴导入 | 实际浏览器操作并记录结果与截图 | 功能连通后；未检查保持待验证 |
| 安全与数据保持 | 非法、冲突、超长和未知版本不写入；文本不执行；存储失败不报成功 | 行为测试、页面审查和对应交互检查 | 导入与存储改动后；失败保留旧状态并说明 |
| 总库约定 | 登记、目录与已有索引结构保持一致 | 仓库根目录 `npm.cmd run check` | 交付前；失败先定位是否由本轮造成 |
| 范围保持 | 本轮文件与既有未提交工作可区分 | 仓库根目录 `git status --short` 与针对本轮文件的差异审查 | 开始与交付前；不撤销其他任务变更 |
| 证据语义 | 25 项覆盖唯一，状态只用本轮采用/待验证/未触发 | 对照快照技能目录及 `real-case-data.js`；人工检查证据对应 | 教学内容修改后；不以覆盖数量宣称全部实测 |

本地命令可重复运行，但本轮未把它们接入 CI，也没有自动 post-edit 钩子。检查失败时由本次执行流程停止交付并修复；不能把这描述成已有不可绕过的远端保护。

## 数据与存储边界

- `projectId` 必须来自当前快照，备份顶层仅 `schemaVersion` 和 `notes`；条目仅 `projectId` 和 `text`。
- schemaVersion 固定为 1；每条最多 5,000 字符，JSON 文本最多 100,000 字符；这是本工具选定的输入界限，不是通用质量指标。
- 同项目冲突不覆盖；空导入文本不抹除已有非空文本；相同文本可重复导入。
- 存储异常需可观察，界面说明当前保存没有成功；不自动清空或重新初始化已有笔记来消除错误。
- 导出由用户操作触发，不把用户笔记写入源代码、研究快照或自动上传。
- 来源哈希用于一致性，行号用于回到依据；两者均不替代研究结论核验。

## 检查成本与性能

优先运行与变更相关的快速语法和行为检查；浏览器检查覆盖完整使用路径。已有通过结果在代码未变时不重复执行。数据规模、输出体积和运行耗时可以记录，尚无项目测量前不设置任意覆盖率或性能分数，也不声称优化收益。

## 规则自身也需要检查

交付审查应查看：是否添加跳过测试，是否删除失败断言，是否放宽备份格式，是否把错误改为成功，是否弱化语义边界。这里采用实际差异和测试结果核对，没有安装上游 floor-guard，也没有声称其参考实现已在本机强制运行。

## 例外与未覆盖

当前无约束例外。浏览器本地存储不是云备份；清理浏览器或改变 origin 可能使当前页面看不到原笔记。跨浏览器兼容、多人协作、生产监控、线上 CI、迁移升级均需独立需求与验证。本轮不证明没有全部安全缺陷，也不量化 Skill 的因果收益。
