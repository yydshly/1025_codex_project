# 真实事件包扩展合同 · v1

本文件定义后续接入规则。当前数值实例为 JMA 2018 山竹事后最佳路径：46 条原始记录。新增影像以媒体清单记录实际覆盖。通用事件注册器、站点时间序列、地震、火山、河流及设备真实数据适配器尚未全部实现。现有 `mangkhut-jma.json` 保留简洁字段；新增通用格式时通过适配器读入，不改写其原始记录。

## 一个事件包解决一个用户问题

事件包应让用户回答：什么时间、什么地点、发生了怎样的变化、判断来自什么证据、哪里还不知道。先明确问题，例如“山竹过吕宋前后中心强度怎样变化”，再选择原始路径、强度序列和相关影像。关于香港强风与风暴潮的解释另引官方报告，不能从中心风速自动推断站点风或受灾程度。

地球负责定位和跨区域联系；时间线只选择资料支持的时刻；图表展示原始量和明确标注的计算量；图片或视频提供可核对的外观证据。图像、参数动画和曲线不能互相冒充证据。

## 最小字段合同

| 字段组 | 必须表达 | 读取与展示规则 |
| --- | --- | --- |
| `id / title / eventType / schemaVersion` | 稳定事件 ID、名称、类型、合同版本、面向用户的问题 | 同名事件用年份、来源 ID 区分；升级适配器不覆盖原始版本 |
| `geometry` | 几何类型、经纬度或局部坐标、坐标系、坐标顺序、单位、定位依据 | 地球位置使用明确 CRS 和轴顺序；GeoJSON 明确 `[lon, lat]`。设备内部坐标写明参考原点与米／毫米；几何缺失时不伪造位置 |
| `time` | 观测或分析有效时刻、UTC ISO 字符串、覆盖区间、原始时间分辨率；另存发布时刻 `issuedAt` 和下载时刻 `retrievedAt` | 观测／有效时间、发布时间、下载时间不能混用。UI 可转北京时间，存储保持 UTC；时区不明暂不参与同步 |
| `observations` | 量名、数值、单位、采样或平均时长、测站／位置、质量标记、有效范围、来源记录 ID | 直接观测、遥感反演、事后分析、预报、模型输出分别标明；每条曲线对应明确量。只有来源明确报告为 0 时才画 0 |
| `media` | 入口／资产 URL、类型、采集起止时刻、时间精度、传感器／通道、空间范围、原投影、处理说明、许可 | 无逐帧时标的视频独立播放；无投影或定位的图片在旁栏显示，不能直接覆盖球面。日合成注明整日覆盖，不标瞬时时刻 |
| `provenance` | 机构、原始 URL、产品与记录 ID、版本、修订日、下载日、原始文件哈希、许可／署名、解析脚本版本 | 数值和图像均能回到原始资料；保留机构分歧，不自动拼成单一真值 |
| `missing / quality / revision` | 缺测原因、原始缺测 token、质量、修订前后版本及变更摘要 | `null` 留空或断线；不补零、不延长最后一帧假装仍在观测；新版本不能无痕替换历史结论 |
| `derived` | 输入记录 ID、公式或算法、单位、参数、模型版本、适用条件和误差说明 | 换算、插值、距离估计、模型预测与观测分开标记。计算结果不宣称新增测量 |

数值用 JSON 数值或 `null` 保存，不用字符串 `"N/A"` 混入同一字段。量与单位分开；风速平均时长和水位基准面属于量的定义。JMA 的 10 分钟中心最大持续风、站点 10 分钟平均风、阵风是不同指标。

## 时间与画面怎样对应

1. 加载原始数据后验证事件名、日期、递增顺序、坐标、指标单位与空值；失败时显示错误，不能改用模拟样本。
2. 地球、当前值与图表游标选择同一个真实记录 ID。记录间路径连线不能增加测量点。
3. 媒体有自己的采集区间。选择邻近影像时同时显示影像时间、记录时间和时间差；超出产品支持范围时显示“无同期影像”。日合成只能按日关联。
4. 图片具备投影与空间元数据后，才能按可复现重投影流程叠球。保存原图、输入／输出 CRS、重采样方法与覆盖掩膜；不能把裁切截图拉伸成全球云层。
5. 真实卫星图层使用与资料含义一致的色标，不加改变观测含义的装饰光照。地理底图可以美化，但始终标为背景。
6. 风场粒子需要有明确时空分辨率的矢量场，并标为场的可视化，不能称为真实空气质点轨迹。云顶、灰柱高度与震动幅度各需数据，不从外观猜测。

山竹路径按 46 个 JMA 分析时刻选择；GIBS 全球日合成按真实可用日期更新，缺日退回地理底图且明确标注，不补帧。NASA 局部图片和官方视频保留各自资料时间。高频历史 Himawari 图层仍须核验具体通道、日期与覆盖，不能从有一幅日合成推断已实现完整逐分钟回放。

## 分步扩展

| 顺序 | 用户价值与第一步 | 首批资料和呈现 | 完成条件与边界 |
| --- | --- | --- | --- |
| 1 · 更多台风 | 看懂一次事件演变，再比较不同事件 | 复用官方最佳路径；补山竹同期高频影像与可下载站点序列，为每个事件关联官方资料 | 按机构与风速平均时长分开；逐帧时间、空间配准和权利明确后再叠球。预测轨迹与事后分析分开 |
| 2 · 地震 | 看懂何时何地发生、哪些测站记录到变化 | 事件目录中的震中、震源深度、震级类型与时间；接入真实测站波形或官方震动分布产品 | 目录点不能单独支持波纹传播动画。模型波前注明介质、参数和不确定性；官方震动估计不能写成每点实测 |
| 3 · 火山 | 了解喷发报道、观测与范围变化 | 官方监测报告、带时标卫星／热异常产品、已核验地形和可用现场影像 | 热异常不直接等同喷发；灰柱高度不从一张图猜出。取得高度／浓度产品才展示相应量，无三维观测时保持二维证据 |
| 4 · 河流与污染 | 看懂上下游监测随时间怎样变化 | 河网、监测站、流量／水位、水质指标与采样时刻；先显示各站原始数据 | 监测浓度不等于整段浓度场。连续羽流需污染源、边界条件、水动力／输运模型和验证，并标为模型推算 |
| 5 · 电池或发动机 | 复盘设备状态，定位变化时刻与部位 | 获授权的传感器遥测、采样时钟、量程、结构与标定信息；从设施点进入局部视图 | 外壳温度不等于内部温度；SOC 等估计量注明算法；内部热场／应力场注明模型。先解决授权、时钟同步与设备隔离 |

以上是产品顺序和验收条件，未声明各类数据源均已接通。优先复用数据合同和时间控制；图层依据资料形态选择点、路径、栅格、波形或局部模型，不要求所有现象都使用粒子特效。

## 进入真实事件列表的条件

来源与许可可追溯；原始记录可抽检；单位、时区和坐标明确；缺测不伪造；空间、数值与时间对应；图例说明量的性质；媒体与图表有时差时可见；断网或空数据时不替换为假数据。未全部满足的材料可留在资料入口或待接入清单，不宣称完整回放。

验收抽查开始、峰值、衰减与缺测时刻，至少核对一条原始行与屏幕值；媒体检查日期、位置和色标；修订后确认旧版本仍能读取。机器检查验证结构与数值关系，来源准确性和用户理解仍需人工核验。
