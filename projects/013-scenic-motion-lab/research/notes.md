# 013 · 景观奇旅研究记录

[项目说明](../README.md) · [参考原作](https://x.com/hi_personality/status/2115567493565825244)

记录日期：2026-10-31。本次整理依据会话中已经完成的观察、生成与本地审片文件，没有重新查询外部服务。下面的沟通过程是按意图重述，不是逐字聊天记录。

## 当前理解、能力与下一步

本质是六个相互关联的创作选择：**世界与首图 → 人物行动 → 摄影路径 → 环境响应 → 时间剪辑 → 审查迭代**。图生视频根据图像、文字等条件生成时序画面；呈现出来的空间并非已重建的可交互3D场景。首图质量、模型版本与输出分辨率是制作变量，不能自动确保接地、路线、摄影和跨片连续性。

当前新增的《悬崖长卷》以Kling 4.0 A任务1044781的真实第120帧建立B任务1044794首图。A取第0–119帧的5秒，B取全部145帧的6.041667秒；两原片1284×724、24fps，最终归一为1280×720、265帧、11.041667秒，在5.000秒真实硬切，没有循环、定格、变速或溶解。接点基本承接，仍有人物与花草轻微重绘，A略靠近、B明显拉远。B确认180积分，A最终费用未知；音频未听验。历史8.375秒跃岭试验保留在下文，与这次两片记录分开。

可复用的连续性方法是：使用真实输出状态接力，B先延续方向和速度；对照接点前后至少0.5秒，全景检查地理光向，近裁检查脚踏、双轮与接触；按实际帧剪接，避免相似边界姿态双播。姿态重置、突然加速、重复起步、断路或换光向都是失败信号，不能靠溶解、循环或定格掩饰。同一边界图只能帮助建立外观起点，不能传递精确速度或骨骼状态。

提示词也按职责拆开。首图写“观看收获、世界层次、主体身份与尺度、连续路线和朝向、光线材质、尚未揭示的空间”；视频写“主体行为、相机路径、环境响应、结果与延续、跨段约束、可见验收点”。详细模板仍为研究后整理，不冒充历史实际提交。每轮先修一个主要偏差，再决定是否提高规格。

价值是可感的景观探索体验与可以复用的导演方法。近期可试系列景观旅程、品牌／文旅概念样片；动作摄影模板与首尾接力已有手工流程，产品化尚待建设；互动创作工作台可先做首图、路线、镜头、版本和证据的交互原型。分别验证跨段身份、主题表达、复用返修和创作者修正效率，不把构想写成商业成品或收益。当前不是精确骨骼／路径控制、自动长片系统，也没有通用模型排名证据；其余六个扩展方向视频未生成。

主站`#understanding`集中呈现这份摘要；`overview.html`保留专门生成的原总览图，在旁边补充最新11秒结果并引导到成片与文字。原长图是首轮研究快照，未重画。

## 研究对象与证据等级

原作为 Personality（@hi_personality）的《grassland special》。本地分析视频为 1920 × 1080、60 fps，共 418 帧；按帧数计算约 6.9667 秒，最后一帧时间为 6.95 秒。平台提取元数据给出约 6.976 秒，两种口径都支持“约 6.97 秒”，不应把这点差异当成另一个剪辑版本。

作者在[公开回复](https://x.com/hi_personality/status/2115573454628106332)中确认调色与 HDR 使用 DaVinci Resolve。我们没有本片的模型、节点图或完整制作工程；作者另一条旧视频提到 ComfyUI，只能证明那条旧视频的表述，不能外推本片。饱和度、对比度、HDR 交付和色彩管理是不同概念，不能因为画面鲜艳就判断动态范围或工具链。

## 沟通怎样推动方法变化

### 1. 从理解风格到建立首图

用户最初询问原帖描述的风格及主页中的效果如何实现。起点是理解奇幻景观的构成：宏大悬崖建筑、蓝色海湾、云和日光、前景草坡，以及提供尺度的小骑车人。生成了一张 16:9 图，作为后续图生视频的起点。

用户追问是否用这张图加提示词生成视频，流程随之转为实际制作。第一版选择固定广角、低运动的五秒镜头，意图保持大景观和小人物。这个选择把“保护构图”放在前面，也限制了追随与进入空间的能力；随后发现的静态感应回到这个决策检查，而不只归咎于模型。

### 2. 模型和高清试验没有自动解决摄影

首个 Seedance 2.0、720p 任务 1044252 已完成。Kling V3 任务 1044264 已提交，但截至归档未取得成片，查询曾出现连接问题；**没有明确失败证据，不能写成生成失败**。后续 Seedance 2.0 完整版 1080p 任务 1044280 已交付，实际为 1916 × 1080、24 fps、约 5.041667 秒，已确认消耗 150 积分。

用户关注的是原作中相机与骑车人的运动关系。1080p 增加输出细节，不能重写镜头路径、身体动作或景观揭示。我们据此把“输出规格”和“创作是否成立”分开：探索阶段用合适的视频模型做较低分辨率短样，效果成立后再提高交付规格。

### 3. 看完整时间过程，而不只看封面

对约 6.97 秒的完整原片抽取 0、0.5、1……6.5、6.9、6.95 秒帧，形成时间轴。开头人物较小，相机逐渐接近；摄影位置改变带来人物尺度、前景遮挡和建筑视角的变化。近处草地与岩石经过更快，远处海湾和峭壁变化较慢。相机随下坡与弯道继续移动，末段打开另一角度的海湾，而不是把整幅画面均匀放大。

人物、镜头、路线和景观彼此有关；“画面中有运动”不等于已经形成这种关系。对照图中的原片预览曾做 HDR 到 SDR 的显示映射以便观察；原视频没有被改写，预览色调也不能反推作者的调色节点。

### 4. 验证接近与追随，再重新确认主次

任务 1044377 使用 Seedance 2.0、720p、5 秒、首尾图和文字。实际指令强调 0–1.5 秒迅速接近、主体达到约画面高的 60–70%、随后近距离追随，再沿弯道改变视角。这个比例属于验证“接近是否发生”的局部试验，不是后来景观主导作品的永久验收线。

原片约 5.041667 秒；剪辑预览将前 2.5 秒做 2× 变速、后段保持原速，得到约 3.791667 秒。速度变化来自后期，不是模型原生完成的时间设计，也没有新增一次 AI 生成。

用户进一步明确：美景是主舞台，人物和动作负责带路；不能为了接近人物而丢掉景观。方法从“追得更近”推进为“行动带来新的景观与情绪收获”，并要求先设计完整事件和结尾。

### 5. 设计完整短片

《越过山脊，看见海湾》原计划两段各 5 秒，Seedance 2.0 完整版、720p、16:9。三张关键图分别承担：

| 图 | 设计职责 | 审查风险 |
| --- | --- | --- |
| start | 接近低矮山脊，部分海湾被遮挡 | 海湾已部分可见，揭景要来自水面进一步打开，不能声称从无到有 |
| apex | 小幅离地最高点，海湾展开，前下方有落地路线 | 路面能否连贯，跳跃是否过高，目标姿态是否真在结尾实现 |
| end | 接地后沿弯道继续，景观保持主导 | 路线、主体尺度、地理和光线是否延续 |

实际传入关系为 A：start → apex；B：apex → end。原作视频只供人工分析，**没有作为视频参考传给生成模型**。图片外观、首尾目标、动作文字与摄影文字分别承担职责，不能笼统写成“用了原视频参考”。

本地 CLI 会构造 `function_mode=first_last_frames` 并顺序放入两张图。后续对 A/B 服务端存储输入的只读核对共尝试三次，均未得到完整历史响应，因此只能记录本地构造与提交方式，不能声称已核实服务端保存值，更不能推断模型内部是否把图当成硬约束。

## 完整短片的实际结果

### A：没有严格执行设计尾帧

A 的任务号 1044472，约 5.041667 秒、24 fps，实际消耗已确认是 75 积分。密集抽帧记录如下。

| 项目 | 观察 |
| --- | --- |
| 完全离地 | 约 2.833–2.917 秒 |
| 视觉高点 | 约 3.25–3.75 秒 |
| 落地 | 约 4.667–4.75 秒 |
| 腾空时长 | 约 1.8 秒，明显长于预想的小幅短跃 |
| 结尾 | 已接地并继续下坡，不是指定 apex 的姿态、尺度和位置 |
| 景观揭示 | 山脊后退，更多海湾水面出现；开头已有部分海湾 |
| 主要不足 | 跳跃过高、过长，起跳预压和落地吸震较弱 |

实际指令要求前四秒保持可信接地、临近结尾才小幅起跳并停在 apex，结果没有按这个时间表执行。首尾图和分秒文字表达目标，不能当成动画时间轴的硬控制。

### B：有落地和吸震，不能再重复一次事件

B 的任务号 1044477。密集抽帧显示，约 0.375–0.5 秒轮胎落地，约 0.625–0.75 秒身体压缩缓冲，之后沿下坡弯路继续行进，并有前后景层次运动。费用字段返回 `N/A`；实际消耗未确认，不能因为 A 也是五秒、相同模型就推断成 75 积分。

B 的首次提交曾出现无任务回执的连接问题。两次只读历史检查未找到精确提示词与首尾图顺序匹配，但仅覆盖可见历史范围，不能证明原提交永远不会入库；后来同一计划取得任务号 1044477。恢复过程应保留为执行事实，不写成模型明确失败后的创作重试。

### 最终剪辑依据真实动作调整

A 已经落地，直接接 B 的腾空开头会造成落地后又回到空中的动作倒退。最终保留 A 的一次完整事件，跳过 B 的初始腾空和落地，在其接地续骑阶段换机位。

最终《越过山脊，看见海湾》为 **8.375 秒、1280 × 720、24 fps、201 帧**。

| 段落 | 实际处理 |
| --- | --- |
| A 帧 [0, 68) | 1×，保留接近与起跳前段 |
| A 帧 [68, 114) | 2×，缩短腾空中段；不是插帧或新增生成 |
| A 帧 [114, 121) | 1×，保留接地后的短暂延续 |
| B 帧 [18, 121) | 从接地后续骑开始，舍弃重复腾空与落地 |
| 拼接点 | 约 4.083333 秒，明确的两机位硬切 |

独立审片未在所检全片与密集拼接帧中发现重复起跳、第二次落地或动作倒放。它并非单镜头原生生成，硬切处人物尺度、海湾地理和色调仍有可见改变；A 的跳跃高度仍夸张，蓄力与吸震不足，身体和自行车几何也不保证逐帧完美。变速缓解腾空拖沓，不能修复全部物理问题。

## 可复用制作方法

1. **先写观看收获。** 观众开始看见什么，行动后多看见什么，结尾留下什么感受；不要从堆叠画质形容词开始。
2. **设计能揭示的空间。** 选择前景遮挡、真实路线与有层次的远景，给行动前后两个不同的观看位置。
3. **拆开主体与摄影。** 分别写人物朝向、速度、接触关系，以及相机位置、距离、路径与转向；人物变大要有相机接近的解释。
4. **先设计整片，再定分段。** 动作有准备、发生、结果和延续；跳跃只是选项，安静转弯或驶出遮挡也能揭景。
5. **明确参考角色。** 标记身份、外观、首帧、尾帧或情绪参考；没有传原视频就不写成模型看过原片。
6. **较低分辨率验证动作。** 先审空间、物理和节奏，后决定高清交付；一次短样优先验证一个核心假设。
7. **沿时间审片。** 每 0.5 秒看全画面，起跳、落地与接缝以 0.125 或 0.25 秒加密；全画面判断地形，局部检查接触和几何。
8. **按实际结果剪辑。** 避免重复事件与动作倒退，必要时明确换机位；不能用过渡遮掩地形错误，也不能把变速说成模型原生能力。
9. **保留原件与不确定性。** 原件、剪辑、变速、调色分别留档，写清实际参数、偏差、未知费用和下一次只改哪一项。

## 审片标准

| 维度 | 通过迹象 | 需要返修的迹象 |
| --- | --- | --- |
| 景观主次 | 景观持续值得看，人物给出路线和尺度 | 人物无目的占满画面，景观沦为贴图 |
| 摄影空间 | 近远速度、遮挡和视角随路径改变 | 统一缩放，背景固定或结构漂移 |
| 行动价值 | 动作揭示新景物或改变情绪、尺度 | 为了运动而运动，没有观看收获 |
| 物理接触 | 接地、离地、下落、接触、吸震连续可读 | 长时间悬停、路面突变、落地后返回空中 |
| 几何与身份 | 人、车、衣着和两轮关系稳定 | 多人、多车、车架融化、轮数变化 |
| 时间结构 | 开头建立、事件发生、结果明确、继续前行 | 只有漂亮腾空姿态，缺少结果与结尾 |
| 跨镜头连续性 | 换机位后仍能理解路线与方向 | 突然换地形、色调或朝向且无空间解释 |
| 证据与声音 | 原生/剪辑区分，视听验证分别说明 | 用音量数据声称听过；用高清证明动作成功 |

## 新方向与模板

本地网页继续展开七个不同景观与行动方案，分别说明首图、主体行动、氛围、摄影、揭示事件与验收条件。新概念视觉属于方向探索；不代表七条视频已生成，也不代表首尾图能精确约束运动。

`app/data/research.js` 的首图、视频、参考角色、定向返修提示词均为**研究后新整理的中文模板，不是历史实际提交指令**。复制前替换方括号变量，确认输入方式与输出参数，再用短样验证。不要把互相冲突的“锁定构图”与“大幅接近转向”同时塞进同一镜头。

本轮用户已授权补充理解后远端静态发布。静态网页已于2026-10-31发布并完成远端核验；本地服务界面证据与公开展示副本分别管理。
