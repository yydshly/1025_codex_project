# 014 · 研究方法与五个产品方向

50 站分为地球与动态监测、地图与空间探索、互动科学与天文、数据理解与叙事、知识与数字档案、艺术与文化策展、音乐与声音探索、时间与科研发现等能力方向。以具体页面和原始证据为单位记录。优先级基于个人或小团队能否用可获取资料完成首个样例，用户需求和市场价值待验证。

| 方向 | 首个问题 |
| --- | --- |
| 带出处的专题资料工作台 | 能否从多篇资料中找到原句，并看出出处和时间？ |
| 专题数据故事工作台 | 能否把一次数据变化整理成有图表、有口径和有出处的故事？ |
| 围绕一个问题的科普解释页 | 能否让初次接触的人通过操作和实测看懂原因与结果？ |
| 文化素材板与微展览 | 能否用可核对出处和授权的作品组织一个小专题？ |
| 一个街区的时空故事 | 能否用不同时期的地图和图像解释同一地点的变化？ |

[观象](../../015-process-visualization-lab/README.md)展示了其中的科普与数据叙事方法。[资料理解与检索研究](../../009-knowledge-processing-atlas/README.md)可以用于对照资料解析、检索与出处的做法。
