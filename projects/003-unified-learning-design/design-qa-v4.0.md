## 验证结果

浏览器实际走过图例、滚动预测、谷底停帧、耗散对照、弹簧准备、最高点停帧、落地、结束等九个段落。验证了音频实际播放：readyState = 4、paused = false、currentTime 增加；暂停后多次读取时间不变；重播回到起点；静音状态生效。未用仅有 audio 标签代替播放验证，也未把合成语音描述为真人声音。

在耗散运行中暂停：音频保持 0.093506 s，势能 5.14 J、动能 0.30 J、内能 0.01 J 保持不变；恢复后继续变化。谷底动能约 5.45 J、势能约 0；最高点动能约 0.08 J、势能约 1.20 J，水平速度约 1.62 m/s。落地后约 1.278 J 转入内能。显示值按各自精度四舍五入，分项两位小数相加可能与三位小数总量有末位差异。

自由模式实际检查：起始高度、滚动耗散、松开、压缩量 15% / 100%、阅读入口、翻页、导览退出及重新进入。低压缩量提示与槽内往返对应；100% 发射落在软垫范围内。桌面、手机与中屏没有出现主操作被面板挡住。

子项目 npm run check、npm test（5 项）及根目录 npm run check 通过。语音生成脚本实际重建 9 段 WAV，总时长 157.8 s。浏览器控制台未发现本轮运行的 warn/error。

## 五项视觉检查与边界

- 字体：沿用纸页衬线与手写风格；字幕使用中文无衬线。全景正文用于概览，仍通过阅读视角／面板查看长文。
- 布局：书本作为连续载体；讲解在大屏左侧、窄屏下侧；实验主体与下一步同时可见。
- 颜色：沿用暖纸、灰绿桌垫和能量类型色；图例不再填入未经计算的 J 数值。
- 模型：轨道球心贴合曲面法线，弹簧实际伸缩，最高点显示水平速度箭头，着地使用软垫示意。
- 内容：语音、字幕、物理事件、读数与按钮共享段落定义；无空气阻力、无滑动、完全非弹性等假设在阅读说明与模型文档中列出。

这仍是三课独立样章，不是原站完整复刻。语音为合成输出，尚未经过真人配音润色；没有真实触屏设备或手机 GPU 基准测试，没有完整辅助技术审计和学习者教学效果试验。音频失败时的字幕降级已实现，未通过破坏文件或浏览器权限强制触发故障。

## 暂停观察修复

修复导览开启后始终禁用拖动／缩放的问题。显式暂停或关键点停帧时允许环视、滚轮和已有的双指缩放；关键点首次手势会暂停讲解，避免观察途中自动推进。手势不操作实验物体；轻点小球也不释放实验。继续、换段和退出时清理旧手势，继续后恢复当前导演镜头。

实际浏览器复查：从小球上轻点并拖动、滚轮靠近，视角发生变化，语音始终为 0.01526 s，势能 5.11 J、动能 0.34 J、内能 0 保持不变；继续后语音和运动恢复、镜头回到导演预设。谷底停帧时也能拖动并转入暂停观察。控制台无 warn/error；脚本语法、五项既有物理测试与根索引检查通过。双指未在真实触屏验证。

证据：[暂停前](assets/images/pause-before-orbit.png)、[暂停时环视与缩放](assets/images/pause-orbit-zoom.png)。这项修复不表示此前审查记录中的碰撞、回退和面板冲突已解决。
